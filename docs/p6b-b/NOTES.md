## 2. #12 駐車場の裏世界 — 真因

**再現**: 敷地 'G' の外周の内側と車 3 台の周りを 0.25m 刻みの起点(1081 点)× 16 方向に 0.5〜0.67 秒走らせる総当たりで、703 回が **1F の当たり**に化けた。位置は x 15.61〜19.6・z 3.41〜12.9 = 建物の北東の自転車置き場(敷地の矩形 `[14.92, 3.02, 4.6, 10.16]`)。

**真因**: `main.js` の `updatePortal()` が「x が玄関の線の範囲(15.6〜19.6)にあるか」と「玄関の線(z 28.1)より北か」しか見ていない。自転車置き場は玄関と同じ x の範囲で、z 28.1 より北にあるので、敷地 'G' → 1F に切り替わる。1F の当たりでは建物の外に壁がなく、外観・外環境も描かない(屋内扱い)ため、暗闇の中を自由に歩けて、北階段(屋外の鉄骨)と東棟の 2F のバルコニーを見上げる構図になる(ユーザーのスクショと一致)。車・柵・建物の裏の当たりの欠落ではない。

**修正**:
- (この工程) `story.js` `_fixSiteLevel`: 1F の当たりなのに 1F の外形の外・敷地の矩形の中にいたら、同じ位置・向きのまま敷地 'G' に戻す(`story.update` は `updatePortal` の後・AI と描画の前なので、化けたフレームは画面に出ない)。物語の段に関係なく毎フレーム(`?test=building` などの 'off' でも)働く。
- (根本・未適用) §5 の main.js の 1 行: 玄関の線から 1.0m 以内でだけ切り替える。HEAD の複製にこの差分を当てて `?test=building&only=8` を回すと、8c で `_fixSiteLevel` が働いた回数 0・8 番(玄関の出入り)も通過。適用後も `_fixSiteLevel` は保険として残してよい(働かなくなるだけ)。
- 現状(main.js 未適用)では、自転車置き場にいる間は毎フレーム 'G' → 1F(main)→ 'G'(story)と階の切り替えが 2 回走る(当たりの差し替え・`levelLog` が伸びる)。描画・操作には出ないが、無駄なので main.js の差分の適用を勧める。

**機械テスト**: `?test=building` の `8c_site_bruteforce_no_escape`(上の総当たり。どの 1 歩でも 'G' のまま・敷地の矩形の外 0.05m より外へ出ない・床の高さ 0)。修正前 703 件 → 修正後 0 件(17,296 回)。所要 約 100 秒。

## 4. 既知の妥協点

1. **北階段の 2F/3F は扉から 1.0m に着かない**: 鉄扉は屋外通路の西の端(x 7.8)で、段の口(x 15.4)から 6.7m ある。扉から 1.0m に着けると、着いた後に約 5.6m(約 4.5 秒)操作を奪って歩かせることになる(最終追跡では管理人が階段を使う)ので、段の口の外(x 14.5)に着いて扉の方(西)を向くだけにした。1F は地面の小さな囲い(扉なし)で、建物の方を向く。扉まで歩かせる方がよければ `STAIRS.exits.north` に 2・3 の点を足すだけ。
2. **地下階段は扉の正面ではなく斜め**: 踊り場が 1.6m しかなく、口の外 +0.3m(x ≤ 8.5)だと扉の正面では 0.7m にしかならない。扉から 1.0m を優先して (8.5, 2.16) から斜め(約 45°)に扉を向く。
3. **#13 の「曲がり 3 回」**: トンネルから北向きに入り、作業場の入口も北向きに入るので、直角の曲がりは偶数回にしかならない。迷路の中の曲がりを 3 回(北 → 東 → 北 → 東)にし、行き止まりの脇(左手)が作業場の入口になる形にした(入口へ入る時にもう 1 回向きを変える)。作業場の灯りが見えるのは最後の曲がりの先(入口から直接は見えない。仕切り 2.05m が目の高さより高いため)。
4. **#12 は main.js の 1 行が根本**: 今は story.js の保険で症状を消している(§2)。main.js の差分(§5)を A レーン完了後に当ててほしい。
5. **6b の「開いたままの扉」は 410(自室)**: 4F で内装のある部屋が 410 だけなので(空室の扉を開けると中が無い)、手前の開いた扉を 410、奥の閉じた扉を 409(空室)にした。廊下の北端から南を見る構図。
6. **#7 の「画面の発光」**: three.js のライトは足さず、画面の emissive と床の加算の光の板で見せた。部屋の壁・天井は照らさない。
7. **#8 の隠れ中の判定**: hud は rooms を持たないので、`rooms.hide()` が立てる `player.hidden` で見ている(main.js を触らないため)。
8. **#4 の札の地**: 410 の札の地を使い、数字の部分だけ地の色で塗りつぶして 1 文字を置いた。縁の線・地の色は他の札と同じ。
9. **test_spaces.js**: 私の変更(312・B1)はコミット済み。納品の時点で A レーンが同じファイルに未コミットの変更を持っている(私は触っていない)。
