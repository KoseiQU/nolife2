## 作り方（再現）
```
tools/build_enemy_final.sh        # 取得・検証 → 07 生成 → 機械チェック → レンダ6枚（M系Mac・GPUで約3分）
```
`enemy_build.py --id 07` の中で `enemy_p1b.py` を呼び、以下を行います。
- **肌**：ENHANCED_SSS（皮下散乱）はそのまま使っています。
  - 頂点ごとのマスクとして T字部・無精ひげ・まぶた縁・目の下・老人斑・額・頭皮を用意しました。
  - Cycles の手続き的シェーダで描いた色・粗さ・高さを UV（4096px）に焼き、高さは numpy で法線マップに変換しています。
  - 中身は毛穴、肌理、額の横じわ、シミと老人斑、白黒まじりの無精ひげ、まぶた縁の赤みと濡れ、T字部の脂の鏡面ムラです。
  - 目は角膜の光沢（コート）を足し、白目を黄ばんだ灰白にしました。
- **髪**：MakeHuman の板ポリ髪は使っていません。
  - 頭皮から4万本のヘアカーブを生やしました。白42%・黒58%のまじりで、帽子の内側は省いています。
  - 眉（900本）は MakeHuman の眉カードの透過を型紙にし、まつ毛（約190本）はまつ毛カードの根元の線に沿って生やしました。
  - 書き出し用には、毛束テクスチャ付きの細い帯（髪3,637枚・眉300枚・まつ毛約100枚）へ変換しています。
- **服**：つなぎ（CC-BY, Elvaerwyn）を加工しています。
  - 34.6k から 12.5k 三角形へ間引きました。ファスナーと襟は保護しています。
  - 元の UV は左右・前後で重なっているので、重ならない UV を新しく作りました。
  - その UV に、元のテクスチャと法線（ロゴは消去）、関節の圧縮皺、腰の横皺、縦のたるみ、膝・肘・袖口・裾のすれ、胸ポケット下の油染み、布目、肩の色あせ、全体のくすみを焼いています。
  - 腕章には縁の縫い糸、生地の目、くすみ、浮き（わずかな波打ち）を足しました。
- **帽子**：自作しました。
  - 頭の形を測り、張りのある円筒のクラウンにしています。上をわずかにすぼめ、天井は丸めました。
  - 硬く平滑なつば（下向き7°、厚み4mm）、鉢巻、真鍮の帽章（無地の楕円ドーム）を付けています。
  - テクスチャは numpy で描きました。綾織り、ステッチ（クラウン上下・縦の縫い目・天井の縁・つばの4列）、縁の擦れ、くすみです。

## 既知の妥協点
- **髪はレンダとゲームで別物です。** レンダは本物の毛（ヘアカーブ）で、ゲーム用は毛束テクスチャの帯です。
  - `07_portrait_export_hair.jpg` を見るとこの距離では近いですが、寄ると帯は平たく見えます。
  - 頭頂は帽子の下なので毛を省いています。帽子を脱がせる演出をするなら、頭頂の毛を足す必要があります。
- **布の皺は法線だけです。** 手続き的な彫り込みを焼いたもので、シルエットは変わりません。クロスシムは使っていません。
  - 関節の皺はやや規則的で、前腕には縞が見えます。
  - 胴は皺が少なく、まだ少し「着ぐるみ」寄りです。
- **つなぎは間引いた形でレンダもしています**（12.5k 三角形、レンダ時は細分化1）。袖の縫い目付近に、わずかな面のカクつきが残ります。
- **肌の細部はテクスチャ解像度に縛られます。** 頭部は約 0.34mm/テクセルで、毛穴は覗き穴の距離でかろうじて見える程度です。
- **目の光沢（コート）はマテリアル設定なので FBX には入りません。** FBX では粗さ 0.05 の単一値です。リアルタイムでどう見えるかは P2 で確認が必要です。
- **FBX の髪・眉・まつ毛・帽子は、頭のボーン1本に重み1で付けています。** Mixamo の自動リグで重みが付け直されると、帽子が首の動きで歪む可能性があります。P2 で確認が必要です。
- **突き抜け0には「当然の面」があります。** つなぎの下の肌は MakeHuman の削除グループで消えているからです。実際に効いているのは首・手首・足首の縁と、帽子の下の頭です。
- **全身の色はやや明るい紺です。** 元の P1 02 より明るく見えます。
- **帽子の型は推測です。** 日本の警備・管理用の制帽を一般化して作ったもので、実在する特定組織の帽子や記章は模していません。
- 顔は MakeHuman の汎用モデルを数値で変形したもので、実在の人物には似せていません。


## 差し戻し対応（P1b-2）
### 何をしたか
| 項目 | 対処 |
|---|---|
| 1. 帽子 | 筒型の制帽をやめ、P1 の 04 と同じワークキャップ型にしました（くわしくは下） |
| 2. 顔 | 大柄な体のまま、顔だけ彫りを深く痩せこけさせました（くわしくは下） |
| 3. 不気味な笑い | シェイプキー `grin` を1本作り、FBX に乗せました（くわしくは下） |
| 4. 凶器 | ハンマーを自作し、07 本体とは別ファイルで書き出しました（くわしくは下） |
| 5. 服の皺 | 規則的な正弦の縞をやめました。肢の軸方向を主にしたノイズの稜線にして、本数を少なく、幅・向き・深さを不規則にしています。腰は同じ稜線を弱めて使っています |
| 6. 手 | 甲の血管（青紫の筋と盛り上がり）、関節の赤みとしわ、黄ばみを焼き、顔と同じ老け具合にしました |

**1. 帽子**
- クラウンは頭の形の包絡に沿わせ、側面はほぼ垂直、天井は広く平らにしました。前立てはわずかに起こしています。
- 下の帯（側面の下 30mm）の上端〜天井は 58.6mm です（機械チェックの基準は ≤60mm）。
- つばは前方 ±55°・長さ 7cm・ほぼ水平（下向き 4°）です。
- 生地は初版と同じ硬い綾織りテクスチャのままです。
- 帽章は外しました（初版の放射状の帽章が警察の記章を連想させたため）。

**2. 顔**
- MPFB のターゲットで作りました。こけた頬（cheek-volume-decr 1.0）、張った頬骨（cheek-bones-incr 0.6）、くぼんだ眼窩（eye-push1/2-in）、こめかみのへこみ（forehead-temple-decr 1.0）、head-age-incr 0.9、head-fat-decr 0.7 です。
- 体の太さ（weight 0.8）は変えていません。
- 肌の焼き込みに次の3つを足しました。
  - 凹面の影：頂点の凹みを計算し、眼窩・頬・こめかみを暗く紫がかった色に
  - 首筋の腱（胸鎖乳突筋）の盛り上がり
  - 無精ひげの点を細かく・灰色寄りに

**3. 不気味な笑い**
- MPFB の表情ユニットを合成して `grin` を作りました。口角を大きく上げる・上唇を引き上げる・唇を開く・目を見開く（左を強め）・片眉（左）だけ上げる、の組み合わせです。
- 口内は MakeHuman の teeth_base と tongue01 を付けました。歯は黄ばませて歯間を暗くし、歯茎と舌は血色を落としています。
- 歯は三角形予算のため 7.1k→2.1k に間引きました。
- 眉とまつ毛は、近くの肌の動きを写して同じ `grin` で動くようにしました。帯メッシュは形状キー、ヘアカーブはレンダ時に頂点を動かしています。
- FBX は、モディファイアを適用した複製に `grin` だけを残して書き出しています。体型ターゲットは基本形に焼き込みました。

**4. ハンマー**
- 全長 39.9cm です。頭は八角の鉄で長さ 10.5cm、打撃面は擦れて明るく、ほかは錆と打痕を付けました。柄は黒ずんだ木で、手元 15cm に黒テープを巻いています。
- 640 三角形、テクスチャ 2048（色・粗さ・金属度・法線）です。
- 右手に握らせ、指を深く曲げています。柄の先は外側・斜め前下へ、頭は左右向きにしました（正面から T 字に見えるように）。
- 書き出しは `build/enemy/hammer.fbx` と `build/enemy/hammer.glb` の別ファイルで、07 本体の FBX には入れていません。
- **原点＝握りの位置、+Y＝柄の先→頭の向き、+X＝頭の長さ方向**です。柄尻は −0.075m にあります。

### 既知の妥協点（追加）
- **帽子のクラウン ≤60mm は「下の帯（30mm）の上端から」測っています。** 縁から天井までは約 89mm です。頭頂が縁の平面から約 8cm 上にあるため、帽子を頭に被せたままこれ以上低くはできません。04 の帽子に近い見え方ですが、帯の高さの扱いに注意してください。
- **笑いは表情ユニットの線形合成です。** 頬の盛り上がりや目尻のしわ（笑い皺）は形状では出ていません。目が笑わないのは狙いどおりですが、口のまわりはやや「整った笑顔」です。顎は開けていないので、下の歯はほぼ見えません。
- **ヘアカーブ（レンダ用）の grin はレンダ時に頂点を動かしているだけです。** ゲームでは帯メッシュの形状キーで動きます。
- **ハンマーは握った状態の .blend でだけ手に付いています。** 書き出しは単体です。P2 で右手ボーンに付けるときの位置・向きは、`attach_hammer`（tools/blender/enemy_p1b.py）の値を参考にしてください。指の中の柄はわずかに指と交差しています。
- **8m 先ではハンマーはシルエットとしてかろうじて分かる程度です。** 頭が光るのは打撃面だけです。
- **服の皺は少なくした分、胴はまだのっぺり寄りです**（「迷ったら少ない方」に従いました）。
- **顔の凹面の影は、焼いたテクスチャにも入っています。** そのため、ゲームのリアルタイム照明で影が二重に乗る可能性があります（P2 で確認が必要です）。
- **歯は間引いたので、寄ると歯の形がやや角ばって見えます。**

## 再修正（帽子ドーム化とハンマー頭の増量）
### 何をしたか
- **帽子**：平らな天井の円筒をやめました。
  - クラウンは頭の形に沿わせたドームで、上部は楕円の丸みで滑らかに閉じています。天井の外面は頭頂＋8.0mm、縁から天井までは 102mm です。
  - 6枚はぎの縫い目を入れ、頂点で集まるようにしました。
  - つばは前だけ（±50°）、出は 6.5cm です。横から見て先ほど下がる弧にし、左右の端も下げました。
  - 縁は同じ紺の細いステッチ帯（6mm）だけです。生地は硬い綾織りのままです。
- **ハンマー**：全長 40cm は維持しています。
  - 頭は角材のような鉄塊にしました（長さ 10.5cm、断面 4.5×4.5cm の面取り四角、打面は 6% 広がる）。

## Mixamo の予備 FBX と、リグ済み FBX へのシェイプキー移植手順
**予備 FBX**：`build/enemy/07_kanrinin_final_noshape.fbx`（21.2MB）
- 本番と同じ 1 メッシュ（頂点 46,295）から形状キーを完全に除いたものです。
- ファイル本体に "BlendShape" も "Deformer" も 0 件であることを確認済みです。本番の `07_kanrinin_final.fbx` は BlendShape 3 件・Deformer 7 件です。
- Mixamo が本番の FBX を拒否したときは、こちらを上げてください。

**移植の手順**（Mixamo から戻ったリグ済み FBX に `grin` / `attack` を戻す）

前提：形状キーの出どころは `build/enemy/07_kanrinin_final.fbx`（形状キー入り）です。Mixamo の書き出しは cm 単位で、読み込むとオブジェクトのスケールが 0.01 になることがあります。比較する前に、両方をワールド座標で揃えてください（Apply › All Transforms、またはワールド座標で比較）。

1. 両方の FBX を同じシーンに読み込みます。Mixamo 側（リグ済み、`mixamo.fbx` とする）は Armature＋メッシュ、本番側（`src`）は 1 メッシュです。
2. Mixamo 側のアーマチュアをレストポーズにして（Pose Position = Rest）、頂点数を比べます。

**A. 頂点数が同じで、各頂点の位置が一致する場合（誤差 < 0.1mm）**
- 頂点順が同じなので、頂点番号で移植します。
- GUI で行う場合：
  1. src の `grin` だけを値 1、ほかを 0 にします。
  2. src を選び、Mixamo 側のメッシュを最後に選んでアクティブにします。
  3. Object › Shape Keys › **Join as Shapes** を実行し、できたキーを `grin` に改名します。
  4. `attack` も同じように行います。
- スクリプトで行う場合（同じ結果）：
  ```python
  import numpy as np
  for name in ('grin', 'attack'):
      s = src.data.shape_keys.key_blocks[name]; b = src.data.shape_keys.reference_key
      d = np.array([ (sv.co - bv.co)[:] for sv, bv in zip(s.data, b.data) ])           # src の移動量(m)
      if not dst.data.shape_keys: dst.shape_key_add(name='Basis', from_mix=False)
      k = dst.shape_key_add(name=name, from_mix=False)
      inv = dst.matrix_world.to_3x3().inverted()                                       # cm/回転の差を吸収
      for i, v in enumerate(k.data): v.co = v.co + inv @ Vector(d[i])
  ```

**B. 頂点数や順番が違う場合（Mixamo が頂点を分割・並べ替えたとき）**

Mixamo 側のメッシュに **Surface Deform** モディファイアを付けて転写します。
1. Target を src にし、レストポーズで **Bind** します。
2. src の `grin` を値 1 にし、Surface Deform の **Save as Shape Key** を押してから `grin` に改名します。
3. src の `grin` を 0、`attack` を 1 にして同じ操作を行い、`attack` を作ります。
4. 最後に Surface Deform を外します。Armature より上に置いたまま残さないでください。

**確認**
- 移植後、`attack`＝1 で顎先が 25mm 以上下がること、`grin`＝1 で口元が 8mm 以上動くことを確かめます。enemy_check.py の該当部分と同じ判定です。
- 歯・舌・眉・まつ毛は 1 メッシュに結合済みなので、同じ手順で一緒に移ります。
- GLB にするときは glTF の morph target として出ます（Blender の glTF 書き出しで Shape Keys を有効にする）。

## Mixamo 用の軽量メッシュとリグ移植（P2 準備）
**本当の原因**：Mixamo の拒否は骨の問題ではありませんでした。API の監視ログに `character_mapper: ERROR occured on generating verlod assets(veroldamo): Internal Server Error` とあり、プレビュー変換（Verold）が FBX の中身で落ちています。疑わしいのは、4096px テクスチャ×13 素材・21MB・Blender 5.2 の書式です。

**方針**：Mixamo からはリグと重みだけをもらい、Blender で本番メッシュへ移します。

### 作るもの
`tools/blender/mixamo_prep.py` を実行すると、本番 FBX から次の4つができます。

| ファイル | 中身 |
|---|---|
| `build/enemy/07_mixamo.obj`（5.9MB） | テクスチャ・素材・形状キーなし、三角形化、Y-up・m・A ポーズ・足元 z=0 |
| `build/enemy/07_mixamo_lite.fbx`（2.3MB） | 同じ形、素材 1 個（無地）・テクスチャ埋め込みなし・形状キーなし（BlendShape/Texture/LimbNode とも 0 件） |
| `build/enemy/07_prod_mesh.blend` | 本番の 1 メッシュ `N2E_07_kanrinin`（形状キー・13 素材・テクスチャ同梱）。移植先 |
| `build/enemy/07_mixamo_prep.json` | 下の頂点数などの記録 |

### 頂点数（対応は最近傍頂点で取る前提）
| メッシュ | 頂点 | 三角形 | 素材 | 形状キー |
|---|---|---|---|---|
| 本番 | 46,295 | 57,879 | 13 | grin, attack |
| OBJ | 位置（v）46,295／UV（vt）込みの組 53,548 | 57,879 | — | — |
| lite FBX | 46,295 | 57,879 | 1 | — |

OBJ は UV の継ぎ目で頂点が分かれるので、Mixamo 側の頂点数は 53,548 前後になる見込みです。

### リグ移植スクリプト `tools/blender/mixamo_merge.py`
**入力と出力**：入力は Mixamo のリグ済み FBX（cm・Y-up・メッシュ名が変わる）と本番 .blend、出力は `build/enemy/07_rigged.glb` です。

**手順**
1. 本番メッシュを読み込み、三角形化します（形状キーも一緒に分割されます）。
2. リグ済み FBX を読み込み、レストポーズのワールド座標（m）で両メッシュの形を照合します。ずれていれば本番側を等倍・平行移動で合わせます。
3. 本番の各頂点に、Mixamo 側の最近傍 4 頂点の重みを距離逆数で移します。形状キーを持つメッシュには Data Transfer モディファイアを適用できないので、Python で直接書いています。結果は Data Transfer の「頂点・最近傍」と同等です。
4. 重みは 1 頂点 4 本までに正規化します。
5. 本番メッシュをアーマチュアの子にして Armature モディファイアを付け、GLB を書き出します（スキン・形状キー・アニメ）。
6. `--anims` で、追加のアニメ FBX（Mixamo の Without Skin）も積めます。

**検証**
- 本番の全頂点が骨に重み>0 であること。
- `mixamorig:RightHand` があること。
- GLB を読み直して、三角形数・形状キー 2 本・アニメ数が一致すること。

**通しテスト（本物がまだ無いので自作のダミーで実施）**
- `tools/blender/mixamo_dummy.py` で、lite FBX に Mixamo 規約の骨 65 本（`mixamorig:Hips` 以下、末端骨込み）と最寄りの骨の重みを付けました。オブジェクトは X 90°・スケール 0.01 の Mixamo 風の変換にし、メッシュ名を "Mesh" に変え、30 フレームのアニメ 1 本を付けています。
- 結果は 8/8 通過です。形のずれ 0、重みなし 0/46,295、骨 65、三角形 57,879 一致、形状キー 2 本、アニメ 1 本。フレーム 1→15 で右腕の頂点が最大 0.61m 動くことも確認しました。
- 注意：glTF の読み込みは骨の表示用に Icosphere を作るので、三角形数はスキン付きのメッシュだけで数えています。

### 実行例
```
B=/Applications/Blender.app/Contents/MacOS/Blender
$B -b --factory-startup -P tools/blender/mixamo_prep.py                       # 軽量版と本番 .blend を作る
# → 07_mixamo_lite.fbx(だめなら 07_mixamo.obj)を Mixamo に上げ、自動リグ後に FBX(With Skin)をダウンロード
$B -b --factory-startup -P tools/blender/mixamo_merge.py -- --rigged ~/Downloads/<mixamo>.fbx \
   [--anims walk.fbx,look.fbx] --out build/enemy/07_rigged.glb
```

### 妥協点
- 重みは最近傍頂点からの写しです。Mixamo 側で UV の継ぎ目が分かれても、位置は同じなので結果は変わりません。
- 指・口まわりなどの細部の重みは Mixamo の自動リグの品質に依存します。顔は形状キー（grin / attack）で動かし、顎の骨はありません（Mixamo のリグに無いため）。
- 本物の Mixamo FBX では、骨の向きや末端骨の有無が違う可能性があります。`automatic_bone_orientation=False` で読むこと、骨名は `mixamorig:` 前提であることの2点は、実物で確認が必要です。
