## 作り方（再現）
```
tools/build_enemy_final.sh        # 取得・検証 → 07 生成 → 機械チェック → レンダ6枚（M系Mac・GPUで約3分）
```
`enemy_build.py --id 07` の中で `enemy_p1b.py` を呼び、以下を行います。
- **肌**：ENHANCED_SSS（皮下散乱）はそのまま使っています。
  - 頂点ごとのマスクとして T字部・無精ひげ・まぶた縁・目の下・老人斑・額・頭皮を用意しました。
  - Cycles の手続き的シェーダで描いた色・粗さ・高さを UV（4096px）に焼き、高さは numpy で法線マップに変換しています。
  - 中身は毛穴、肌理、額の横じわ、シミと老人斑、白黒まじりの無精ひげ、まぶた縁の赤みと濡れ、T字部の脂の鏡面ムラです。
  - 目は角膜の光沢（コート）を足し、白目を黄ばんだ灰白にしました。
- **髪**：MakeHuman の板ポリ髪は使っていません。
  - 頭皮から4万本のヘアカーブを生やしました。白42%・黒58%のまじりで、帽子の内側は省いています。
  - 眉（900本）は MakeHuman の眉カードの透過を型紙にし、まつ毛（約190本）はまつ毛カードの根元の線に沿って生やしました。
  - 書き出し用には、毛束テクスチャ付きの細い帯（髪3,637枚・眉300枚・まつ毛約100枚）へ変換しています。
- **服**：つなぎ（CC-BY, Elvaerwyn）を加工しています。
  - 34.6k から 12.5k 三角形へ間引きました。ファスナーと襟は保護しています。
  - 元の UV は左右・前後で重なっているので、重ならない UV を新しく作りました。
  - その UV に、元のテクスチャと法線（ロゴは消去）、関節の圧縮皺、腰の横皺、縦のたるみ、膝・肘・袖口・裾のすれ、胸ポケット下の油染み、布目、肩の色あせ、全体のくすみを焼いています。
  - 腕章には縁の縫い糸、生地の目、くすみ、浮き（わずかな波打ち）を足しました。
- **帽子**：自作しました。
  - 頭の形を測り、張りのある円筒のクラウンにしています。上をわずかにすぼめ、天井は丸めました。
  - 硬く平滑なつば（下向き7°、厚み4mm）、鉢巻、真鍮の帽章（無地の楕円ドーム）を付けています。
  - テクスチャは numpy で描きました。綾織り、ステッチ（クラウン上下・縦の縫い目・天井の縁・つばの4列）、縁の擦れ、くすみです。

## 自己批評ループ
### 1周目（初回の全レンダを見て）
| CGっぽい所 | 対処 |
|---|---|
| 額と鼻筋が溶けた蝋のように波打つ | 波模様をやめ、額だけに 1cm 間隔の細い横じわを途切れ途切れに入れた |
| 肌の法線マップがほぼ平坦（std 0.007）。Cycles のベイクではバンプが効かなかった | 高さ(m)を浮動小数で焼き、numpy で法線へ変換する方式にした |

| 髪が茶金色で、生え際がまだら・地肌に茶色の描き込みが残る | 色指定の Hair BSDF にして白と黒の毛を混ぜた。生え際は点ごとに判定し、首まで生やした。頭皮は灰色の地肌と毛根の点に塗り替えた |
| 靴が白く飛ぶ（黒すぎるテクスチャの色替えで比が発散した） | 元の黒い作業靴をそのまま使うようにした |
| 間引きでファスナーが裂け目のように見える | ファスナーと襟を間引きから保護した |
| つなぎ全体に水紋のような横縞が出る | 薄い皺を全身に敷くのをやめ、皺は関節・袖口・裾だけにした |

| 三角形数が 67k で上限超え | 髪の帯を 9本に1→11本に1 にし、区間を 3→2 に減らして 55k にした |

## 既知の妥協点
- **髪はレンダとゲームで別物です。** レンダは本物の毛（ヘアカーブ）で、ゲーム用は毛束テクスチャの帯です。
  - `07_portrait_export_hair.jpg` を見るとこの距離では近いですが、寄ると帯は平たく見えます。
  - 頭頂は帽子の下なので毛を省いています。帽子を脱がせる演出をするなら、頭頂の毛を足す必要があります。
- **布の皺は法線だけです。** 手続き的な彫り込みを焼いたもので、シルエットは変わりません。クロスシムは使っていません。
  - 関節の皺はやや規則的で、前腕には縞が見えます。
  - 胴は皺が少なく、まだ少し「着ぐるみ」寄りです。
- **つなぎは間引いた形でレンダもしています**（12.5k 三角形、レンダ時は細分化1）。袖の縫い目付近に、わずかな面のカクつきが残ります。
- **肌の細部はテクスチャ解像度に縛られます。** 頭部は約 0.34mm/テクセルで、毛穴は覗き穴の距離でかろうじて見える程度です。
- **目の光沢（コート）はマテリアル設定なので FBX には入りません。** FBX では粗さ 0.05 の単一値です。リアルタイムでどう見えるかは P2 で確認が必要です。
- **FBX の髪・眉・まつ毛・帽子は、頭のボーン1本に重み1で付けています。** Mixamo の自動リグで重みが付け直されると、帽子が首の動きで歪む可能性があります。P2 で確認が必要です。
- **突き抜け0には「当然の面」があります。** つなぎの下の肌は MakeHuman の削除グループで消えているからです。実際に効いているのは首・手首・足首の縁と、帽子の下の頭です。
- **全身の色はやや明るい紺です。** 元の P1 02 より明るく見えます。
- **帽子の型は推測です。** 日本の警備・管理用の制帽を一般化して作ったもので、実在する特定組織の帽子や記章は模していません。
- 顔は MakeHuman の汎用モデルを数値で変形したもので、実在の人物には似せていません。
