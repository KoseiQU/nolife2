# 管理人 候補カタログ（P1）

深夜3時に104室を一室ずつ回る**人間の**管理人。候補は6体です。気に入った**番号を1つ**伝えてください。組み合わせの指定もできます（例:「3の顔で4の服」「1をもっと痩せさせて」）。

- `00_overview.jpg` … 6体の顔を横に並べた一覧（左から 01→06）
- `NN_portrait.jpg` … 顔を見るための写真（中立照明・グレー背景・1200×1600）
- `NN_insitu.jpg` … ゲーム内での見え方（P0bの4F廊下、3.2m先に立たせ、常夜灯＋腰の高さから向けた懐中電灯。カメラはゲームと同じ縦画角68°・目線1.62m・1920×1080）。6体とも同じカメラ・同じ照明です

## 共通の作り（どれを選んでも同じ）
- 表情は「無表情〜わずかに不気味」の範囲（血・傷なし）。目線は正面のプレイヤーの目の高さに合わせてある
- 選ばれた1体は P2 で Mixamo に上げてリグと動き（歩く・見回す・扉を開ける等）を付ける。Mixamo 用の FBX（Aポーズ・テクスチャ埋め込み）は `build/enemy/NN_*.fbx` に用意済み（リポジトリには入れていない）
- 顔・体型・服の色は数値で変えられる（`tools/blender/enemy_defs.py`）。直したら `tools/build_enemies.sh` で作り直す

## 作り方（再現）
```
tools/build_enemies.sh                 # 取得・検証・導入 → 6体生成 → 12枚＋一覧をレンダ（M系Mac・GPUで約6分）
tools/build_enemies.sh --ids "03" --no-render   # 1体だけ作り直す
```
- 人体: MPFB 2.0.18（Blender 公式拡張リポジトリ版）＋ MakeHuman 公式アセットパック。肌・髪・目・眉・靴の一部は CC0、服の多くは CC-BY（作者 Elvaerwyn・Mindfront）。詳細は `assets/LICENSES.md`
- 服は MakeHuman アセットを色替え・加工して使用（ロゴやワッペンは塗りつぶし済み）。ベスト（04）は既製品が無いためシャツから作った簡易品、腕章・名札・徽章の文字は自作
- 実在の人物には似せていない（顔はすべて MakeHuman の汎用モデルを数値で変形したもの）
