# P2d 気づかれ演出 — 引き継ぎメモ

## 1. ハンマーの持ち方
- `ENEMY.hammerFlipAxis = [1,0,0]`：meta の quaternion に、ハンマー自身の X 軸（頭の長さ方向）まわり 180° を掛ける。柄が拳の親指側から出て、腕を下げると頭が前、振り上げると頭が上（`hammer_walk.jpg` / `hammer_windup.jpg`）。X/Y/Z の 3 通りを撮り比べて決定

## 2. 「部屋を知っている」（`EnemyAI.knownRoomId`）
- 立つ条件（`_updateRoomKnowledge`）
  - ①目撃：プレイヤーが扉を通過して室内に入った瞬間から 1.5 秒以内に、管理人の視錐（半頂角 45°）＋遮蔽なし＋15m 以内に入っている（暗さによる視認距離は問わない）
  - ②光漏れ：室内でプレイヤーの懐中電灯が点灯、管理人が廊下側で扉中心から 6m 以内（扉が開いていれば 10m）
  - ③物音（追加）：室内のプレイヤーの物音（走る・扉操作・施錠）を聞いた。「消灯して静かに潜めば安全」は保たれる
- 立つと ALERT で 410 室内の点へ向かう（鍵で入る既存の流れ＝覗いていない場合）
- プレイヤーが部屋を出ると消える。復帰（死亡）でも消える
- 知らない場合：プレイヤーが室内にいて扉が閉まっていれば、管理人は扉の前でノブを鳴らして去る（`door_skip_unknown`）。中に誰もいなければ従来どおり覗いて回る

## 3. スコープ覗き返し（SCOPE 状態）
- 起動：知っている ＋ プレイヤーが室内で覗き穴視点 ＋ 管理人が廊下側・扉が閉 ＋ 割り込み不可区間でない
- 流れ：起点（扉の南 2.35m。北にいれば北端）へ → 巡回の歩きで扉の前を横切る（`scope_pass`、点灯・足音あり）→ 扉脇の壁際（スコープの視野 ±55° の外、(7.42, 6.2)）へ寄り消灯（`scope_hide`）→ 2 秒の静寂 → 早足で扉の正面へ（`scope_return`、grin 1.0）→ 上体を倒し首で起こして頭をレンズの前へ（顔の前面がレンズから約 0.2m、`scope_stare`）→ 0.5 秒で attack 顔 → 鍵束・錠（ここで覗き穴視点を閉じる＝プレイヤーは室内から扉が開くのを見る）→ 扉を開けて CHASE → ATTACK（襲撃ムービー）
- 覗き込みの姿勢：`Enemy.lean`（Spine を前へ倒し Neck で同じだけ起こす）。頭の高さは lean、レンズとの距離は立ち位置で毎フレーム合わせる
- 途中で覗き穴を閉じても演出は止まらない（`uninterruptible`）

## 4. 付随の修正
- 管理人の懐中電灯：当たる面が 2.5m より近いと光量を d² で絞る（1m 先の壁が白飛びして bloom で画面全体が霞んでいた。スコープ越しに横切る場面で顕著）
- 覗き穴の円形マスクの縦横比を描画のたびに描画バッファから取る（解像度を変えると楕円になっていた）
- 経路を引いた後で扉が閉まった場合も、室内の点へ向かうなら扉をまたぐ扱いにする（閉じた扉に押し付けて止まる不具合）
- `window.__N2.paused = true` で本物のループの step を止められる（監査スクリプトが await を挟んで pump する間に、裏で AI が進むのを防ぐ）

## テスト（`?test=enemy`）
- `9_witness_scope_return_out`：目撃→室内で消灯→覗く→通り過ぎ→消える→戻り→覗き返し（顔とレンズの距離・grin・attack）→開錠（覗き穴が閉じる）→OUT
- `10_unwitnessed_dark_safe`：未目撃・消灯で扉の前まで来るが入らずに去る＋室内で点灯すると光漏れで知られる
- `5_locked_door_key_entry` はテスト側で `knownRoomId='410'` を立てる（P2d 以降、鍵で入るのは知っている時だけ）
