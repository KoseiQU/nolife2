# P3b 居室とバルコニー・屋上 — 引き継ぎメモ

P3b-A(EV の追加2件)と P3b(入れる部屋 30 室の内装・全居室のバルコニー・410→屋上A→401 の動線・隠れ場所＝演出②・触れると落ちる物)を入れた。
見た目は階の GLB、当たり・仕掛けの数値は `data/building.json`(`src/interior_layout.js` が作る)が真実。

## 0. P3b-A(EV)

- **カゴの中は常に明るい**: 天井の乳白パネル(`M_CarCeiling`)はカゴのいる階で常時発光(`EV.carCeiling` 0.3 倍。移動中は乗っている時だけ)。
  PointLight(影なし)は「扉が開いている・乗っている・カゴの中に立っている」間だけ点ける(影なしの光は閉じた扉の向こうで点けると壁越しに床を照らすため)。
  扉が開くと暗いホールに明るい箱として見える(P3a と同じ光量)。扉の網入りガラス越しにも天井の発光が見える
- **階数表示がカゴの現在地に追従**: `build/tex/ev_display.png`(呼びパネル上段)・`ev_car_display.png`(カゴの操作盤の黒い窓に重ねた面 `EVCarDisplay_EV*`)を
  **8列(1〜8階)×3段(矢印なし/▲/▼)** のアトラスに描き直し、GLB の UV は1マス分(0..1)のまま、`elevator.js _applyDisplay()` が共有テクスチャの
  `repeat(1/8,1/3)`・`offset((階-1)/8, 段/3)` を書き換える(全階の表示が同じ1枚を見るので1か所の変更で全部変わる)。
  移動中は `displayState()` = 出発階＋(経過/移動時間×階差＋0.4 の切り捨て)で通過階ごとに切り替え、上り▲・下り▼。着いたら矢印なし
- **管理人も同じカゴを使う**(`enemy_ai.js _evRide`): ホールで呼ぶ→来て開いたらカゴの中へ歩く→行き先を押す(`elevator.npcSelect`)→動き出したら姿を消す→
  着いた階のカゴの中に現れ、扉が開いたら降りる。カゴが 45 秒来ない時は従来の瞬間移動。経路の費用は EV＝最初の区間だけ乗るまでの 8＋1階 3、
  階段＝1階 9(1階なら階段、2階以上なら EV)
- テスト `?test=building` に `3c_ev_display_follows_car`(1F→4F を呼ぶと表示 1→2→3→4・▲、天井は待機中も発光、管理人 2F→6F でカゴが 4→3→2→3→4→5→6)

## 3. バルコニー(全 104 室、`balconyOf` → `build_balconies`)

- 外壁側に奥行 1.0m。床(長尺シートの暗い灰)・先端の立ち上がりと見付け・天井(上の階のスラブの下面＝自分の階で描く。上の階の GLB と重ならない)
- 手すり: 1〜3F = 乳白ガラスのパネル＋支柱＋笠木 / 4F 以上 = 格子(上下の桟＋縦桟。縦桟は透過テクスチャ `rail_bars.png` の面1枚・両面・アルファテスト)
- 隔て板: 両端(隣と共有する端は片方だけ作る)。室外機(高い側の端・外壁際。入れる部屋では当たり)・排水口・物干し(洗濯物をバルコニーに干す部屋)
- 外壁の面(部屋の外側)に窓の穴。入れる部屋は引き違いの障子(開く側 = 動くノード `WinSash_<id>`)、入れない部屋は閉じたガラス＋カーテン＋闇
- **入れる部屋のバルコニーだけ footprint に入れる**(外周の壁 = 手すり・隔て板の当たり。落ちない)。バルコニーが廊下などに接する辺は
  壁が「覆われた」扱いで消えるので隔て板の位置に壁を足す(`fillWalls`: 104・603 の南端と横廊下、313 の北端と北階段の箱)
- 掃き出し窓: 当たりは walls.js の `window`(開く側・開いている間は無効)と `wall`(はめ殺し側)。E で開閉(`rooms.js`)。外からも開く
- バルコニー・屋上A にいる間は上下の階も見せる(吹きさらし)。風の音(屋上A 強め・バルコニー弱め、WebAudio の仮音)

- 作り: 防水シートの床・パラペット(0.85m＋笠木。外周の壁の当たりの上)・室外機 3 台と通気管(当たり `roofA.obstacles`)・ルーフドレン・
  4F の北の外壁(縦廊下の北端の窓は外から灯りが透ける)・その上の 4F の屋根のパラペット・外壁の壁付け灯(弱い)。5F 以上の段状の屋根は塊として見える(立入不可)

  屋上を西へ(室外機を避ける)→401 のバルコニーの北端(室外機が踏み台)で E 乗り越える→401 の窓を外から E で開ける→401 の室内
- **解放フラグ** `window.__N2.flags.roofA`(`main.js FLAGS`): 通常は false = 隔て板の前で「乗り越えられない」(E を押すと同じ文言)。`?tour` と `?roofA` で true。
  隔て板は当たり `gate`(常に塞ぐ。乗り越えは演出で越える)。401 側も同じ(401 から屋上へ抜けて 410 へ回る抜け道にならないよう)

## 5. 隠れ場所(演出②)と管理人

- **隠れる**(`rooms.js hide/unhide`): クローゼット(居室 27)/縦長ロッカー(管理室)の前で E → 扉が開いて中へ(0.7 秒)→ 閉じて隙間(折戸の中央 1.5cm＋開き 9% = `ROOMS.hideGap`。目は扉の 11cm 奥)越しに見る。
  マウスで扉の方向の ±0.75rad・上下 ±0.45rad だけ見回せる。もう一度 E で出る。隠れている間 `player.hidden = { room, level, stand, feet }`
- 折戸: 左右の組ごとに外側の板(枠の蝶番)と内側の板(外側の子・逆向きに 2 倍折れる)。回転の向きは結び付けた時に「板が部屋側へ出る向き」を数値で決める
- **管理人(`enemy_ai.js`)の「部屋」を一般化**: `_rid(x,z,lv)` = その点のある部屋(入れる部屋＋食堂・シアター。入れる部屋のバルコニーはその部屋)。
  鍵で入る扉 = 居室と管理室(`_keyDoor`)、食堂・シアターは押して開ける共用扉。移動グラフに部屋の点 `<lv>:R_<id>`(扉をまたぐ辺つき、410 は P0 の `R`)
- knownRoomId の条件(§3.4.1)はそのまま全部屋に: ①入るところを目撃 ②室内の懐中電灯がその部屋の扉から 6m(開いていれば 10m)に漏れる
  ③室内の物音(走る・扉・施錠)。**隠れている間は見えない**(視錐・近接・潜伏の発見をしない)
- **演出②(LOCKER 状態)**: 知っている部屋に隠れた → 部屋へ(鍵で入る)→ 部屋の通路の中ほどから **ゆっくり近づく**(0.42m/s)→ 隠れ場所の 0.74m 前で
  **立ち止まって焦らす 2〜4 秒**(足音が止まる・顎を引いて扉を見る・息遣い `breath`・半ばと終わりに取っ手に触れる音 `handle`・薄笑いが強まる)→
  扉を開けて(折戸が速く開く)0.35 秒 → ATTACK(襲撃ムービー → OUT)。演出中は割り込み不可
- **知らなければ**: 見回り(PATROL)で扉が開いていれば入り(施錠扉はノブを確かめるだけ)、部屋を一通り見る(玄関の先→部屋の中ほど→洋室の奥で見回し・振り返り)→
  出て扉を閉める(`_lookAround`/`SWEEP`)。隠れていれば見つからない
- 潜伏(LURK)の隠れ場所を各階1つ、入れる部屋の奥にも足した(1F 104・2F 222・3F 305・5F 511・6F 610・7F 703)。410 の `r410_back` は内装が入ったので玄関の先(トイレの扉の前の暗がり)へ移した

## 10. 判断に迷った点・既知の課題

1. **入れる部屋の選定**: 各階の向き(西列/東列/南棟/東ブロック)と角部屋を混ぜた。2F の 220(前作の「悲鳴部屋」の印 bloodStain が残っている)は物語が決まるまで避けた。
   管理室(OFFICE)は施錠だったのを入れる部屋にした(「管理人室」を兼ねる想定。物語で変えるなら `ENTERABLE` の1行)
2. **1F の居室にもバルコニー**(地面の高さの専用庭に近いが、契約の「全居室」どおりバルコニーとして作った)
3. **仮の夜空**(`LOOK.skyTop/skyHorizon/skyGround` の縦グラデーション): 窓・バルコニー・屋上から見える空が真っ黒の穴だったため。P3a で合格した外階段・屋上B の空も
   真っ黒から「ごく暗い濃紺」に変わる。本番の空は P3c で差し替える
4. **外の塊(マス)**: 屋上やバルコニーから上下2階以上離れた階が欠けて見えないよう、各階の GLB に他の階の外壁を平らなコンクリートの面で入れた(ライトマップなし)。
   バルコニーや窓は無い簡易な外観。P3c の外観で作り直す前提
5. **月明かり**は部屋の組のベイクだけ(外殻=廊下・外階段は P3a のまま)。南西から。東向きの部屋(406〜410 など)には直接は入らない
6. **カーテン closed の部屋**(109・222・319・413・607): 窓の前を通る時に布を通り抜ける(当たりなし)。開く側を開けた half にするか判断待ち
7. 見回り(PATROL)で、開いている入れる部屋には 60% の確率で入って一通り見る(鍵のかかった扉=プレイヤーが L で施錠、は確かめるだけ)。
   入れる部屋が増えたので1周が長くなった(1室 10 秒前後)。潜伏が主(7:3)なので巡回の予算内で切れる
8. 演出②は「知っている」ことが条件。隠れるところを見られた場合は入室の目撃(①)で知られるので演出②になる。隠れている間に懐中電灯を点けると光漏れ(②)で知られる
9. 落ちる物は死亡・チェックポイントで元に戻さない(`rooms.resetFallables()` はある。物語のチェックポイント設計=P5 で決める)
10. 管理人は屋上A へ来ない(移動グラフに無い。P5 で決める)。プレイヤーが屋上A にいる時に追われると、最後に見た点の近くの部屋の点で止まる
11. 既知: 懐中電灯を近距離の白い面(隔て板・ロッカー)に当てると白飛びしてブルームでにじむ(P2b からの懐中電灯の性質)/ 洗濯物は板の重ね(布の形はしていない)/
    2F の南面のバルコニーの床と 1F の正面玄関の庇は高さが重なる(外観 P3c で調整)/ バルコニーの格子は透過テクスチャなので真横から見ると薄い/
    入れない部屋のバルコニーの室外機には当たりが無い(行けないので不要)
