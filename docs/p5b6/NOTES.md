## 1. 状態遷移

前提:管理人が「その部屋にいる」と知っている(`knownRoomId`。条件は目撃・光漏れ・物音、§3.4.1)。プレイヤーはその部屋に逃げ込んでいる。

```
(ALERT / CHASE / LOCKER / PATROL の経路が、閉じた扉をまたぐ)
  └─ _doorEntry: 扉の前に着いて正対
       ├─ 知らない → 立ち止まって去る(従来の door_skip_unknown。揺らさない)
       └─ 知っている・プレイヤーは中・扉は閉 → hide_roll(kind 'enter', p = enter)
            ├─ 外れ(refuse) → _refuseDoor: hide_stand(1.5〜2.5 秒) → hide_forget(忘れる＋猶予)→ PATROL(立ち去る)
            └─ 当たり(enter) → door_open_in → 入室
                 ├─ 隠れていない → 視認して CHASE → ATTACK(従来どおり)
                 └─ クローゼット/ロッカーの中 → LOCKER: ゆっくり近づく → 焦らす(2〜4 秒)
                      → hide_roll(kind 'closet', p = closet / enter)
                           ├─ 当たり(open) → locker_open → ATTACK(従来の演出②)
                           └─ 外れ(spare) → locker_spare → 手を掛けたまま 1.0 秒 → hide_forget(leaving)
                                → PATROL(_leaveRoom: 部屋を出て扉を閉める)→ hide_left(猶予をここから数え直す)
扉が開いている → 扉の判定は引かない(入室率 100%)。クローゼットなら closet / enter を引く
SCOPE(演出①: 覗いている) → 通り過ぎ → 消える → 戻り → 覗き返し(attack 顔)→ hide_roll(kind 'scope', p = enter)
       ├─ 当たり → ノブ → 扉を開けて CHASE → ATTACK(従来どおり)
       └─ 外れ → 顔を離す → hide_stand → hide_forget → PATROL(覗き穴は開いたまま = 去るのが見える)
```

- 「入らない」と「開けない」はどちらも、呼び出し元の段取り(ALERT・CHASE・LOCKER・SCOPE)をその場で打ち切る。そこから `setState('PATROL')` に移る。
- 巡回の初めに、管理人が部屋の中にいれば `_leaveRoom` が働く(部屋を出て扉を閉める)。
- **去る前に出てくると見つかる**:立ち去りは PATROL 状態なので、通常の視認(視錐・2m の近接)が効く。
  - テスト 33 番:開けずに離れた直後にクローゼットから出る。出てから 0.77 秒で `seen` → CHASE(猶予は `chase` で終わる)→ 襲撃。
  - 扉の前で立ち止まっている間(1.5〜2.5 秒)は割り込み不可。その間に扉を開けても、立ち去りに入った次の瞬間に視認される。

## 2. 判定の時刻と確率

| 判定 | 時刻 | 確率 | 乱数 |
|---|---|---|---|
| 入るか(`enter`) | 閉じた扉の前に着いて正対した時(`_doorEntry`。鍵の段取りの前) | `HIDE_ODDS.enter` | `this._rand()` を 1 回 |
| 開けるか(`closet`) | クローゼット/ロッカーの前で焦らし終えた時(`_locker`) | `closet / enter`(enter が 0 の時は `closet`。1 を超えたら 1) | `this._rand()` を別に 1 回 |
| 覗き返しの後に開けるか(`scope`) | 覗き込み(stare)を終え、ノブに手を掛ける直前(`_scope`) | `HIDE_ODDS.enter` | `this._rand()` を 1 回 |

合計(既定値):

| 状況 | 入らない | 入って去る | 捕まる |
|---|---|---|---|
| 扉を閉めるだけ | 30% | — | 70% |
| 扉を閉めてクローゼット | 30% | 20% | 50% |
| 扉を開けたまま＋クローゼット | 0% | 29%(1 − 0.714) | 71% |

扉を開けたままの時の数は、指示どおり「開ける確率は closet / enter のまま」にした結果。

- 判定は到着ごとに 1 回。入った後は判定し直さない。助かった後は部屋を忘れる。
- 次に引くのは、再び知られて(猶予の後の光漏れ・物音・目撃)またその扉の前に来た時。
- `pCloset > pEnter` を与えた時は、開ける確率が 1 になる。合計で捕まる確率は enter になる(閉めるだけより悪くはならない)。

## 3. 定数(`src/enemy_ai.js`)

| 名前 | 値 | 意味 |
|---|---|---|
| `HIDE_ODDS.enter` | 0.7 | 閉じた扉の部屋に入ってくる確率 |
| `HIDE_ODDS.closet` | 0.5 | クローゼット/ロッカーに隠れた時に捕まる合計 |
| `HIDE_FORGET.grace` | **10.0 秒** | 部屋を忘れた後、その部屋の光漏れ・物音では再発見しない時間(目安 8〜12 の中ほど) |
| `HIDE_FORGET.pause` | [1.5, 2.5] 秒 | 扉の前で入らない時、足音を止めて立ち止まる時間(乱数) |
| `HIDE_FORGET.letGo` | 1.0 秒 | クローゼットの前で焦らし終えた後、手を掛けたまま止まってから離れるまで |
| `HIDE_FORGET.away` | 5.0 m | 猶予の間は、忘れた部屋の扉から 5m 以内の巡回先(隣・向かいの扉・廊下の端・EV)へ行かない |

焦らしの長さ(`LOCKER.tease` 2〜4 秒)は従来どおり。

## 4. URL の上書きとデバッグ

- `?pEnter=0.7&pCloset=0.5`:起動時に上書きする。
  - `main.js` が `hideOddsFrom(PARAMS)` で値を作り、`new EnemyAI({ hideOdds })` に渡す。
  - 数でない値・空の値は既定のまま。範囲外は 0..1 に収める。
  - 片方だけでも可(例 `?pCloset=0.25`)。
- `window.__N2.hideOdds`:`{ enter, closet, open(= 開ける確率), start(起動時の値) }` を返す。
- `__N2.ai.stats()`(`pump` の戻り値)に `hideOdds`・`grace`(`{ room, left_s, leaving, why }`)を入れた。
- 実行中の差し替え:`__N2.ai.setHideOdds({ enter, closet })`。
- 強制の例:
  - `?pEnter=0`:必ず入らない(扉を開けていれば入る)
  - `?pEnter=1&pCloset=0`:入るが必ず去る
  - `?pEnter=1&pCloset=1`:必ず捕まる
- ログ(`ai.events`)に足したもの:

| ログ | 中身 |
|---|---|
| `hide_roll` | `{ kind: 'enter'\|'scope'\|'closet', room, p, r, result: 'enter'\|'refuse'\|'open'\|'spare' }` |
| `hide_stand` | `{ room, why, pause }`(扉の前で立ち止まった) |
| `locker_spare` | 開けずに離れた |
| `hide_forget` | `{ room, why: 'door'\|'scope'\|'closet', grace }`(忘れた) |
| `hide_left` | 出て行って扉を閉めた |
| `hide_grace_end` | `{ room, why: 'time'\|'left'\|'door'\|'chase', after }`(猶予の終わり) |
| `room_noise_grace` | 猶予中の落ちる物は無視した |

## 5. 猶予(忘れる)

- **忘れる**:`knownRoomId` を消し、`lastKnown` を消し、`_grace = { room, until }` を立てる。
- 猶予の間、その部屋について次のことをする。
  - 光漏れで知らない(`_updateRoomKnowledge`)
  - 室内の物音を聞かない(歩き・扉操作の `noise`、`_perceive` の `heard` を落とす)
  - 落ちる物で知らない(`noiseRoom` が false を返す)
  - 巡回でその扉の近くへ行かない
- **目で見られるのは別**:視錐・近接による CHASE は猶予に関係なく働く。猶予は `chase` で終わる。
- **終わる条件**:
  - 時間切れ(`time`)
  - プレイヤーがその部屋を出た(`left`)
  - プレイヤーが扉を開けた(`door`。扉の `target > 0` か開いている)
  - 見つかった(`chase`)
- 管理人が中から出て行く途中(`leaving`)は、管理人自身が開けた扉が開いていても猶予を終わらせない。
- **クローゼットの前で離れた時は、部屋を出て扉を閉め終えた時(`hide_left`)から 10 秒を数え直す。**
  - 離れてから部屋を出るまで 7〜9 秒かかる(実測 8.4 秒)。
  - 忘れた時から数えると、去った後の猶予が 1〜2 秒しか残らなかった。
- 猶予が切れた後は通常の条件どおり。テスト 27 番:室内で点灯していると、扉から 6m 以内の管理人は猶予が切れた直後に `light` で知る。

## 6. 判断と申し送り(ユーザー判断待ちを含む)

1. **空室の「ガタガタ扉」(`door_fx.js`)は残した**。
   - ユーザーの「扉のガタガタ演出も無しにします」がこちらも指しているなら、`door_fx.js` の `rattle()` と自然発生(`rattleT`)を止める必要がある。テスト 20 番の書き換えも要る。
   - この演出の音(`slam`/`room_door_rattle`)は P4c の担当範囲。
2. **スコープ演出①も確率に従う**(指示どおり)。
   - 覗き返し(顔が画面いっぱい・attack 顔)までは必ず見せる。開けるかは直前に enter で引く。
   - 外れると顔を離し、扉の前で立ち止まって無言で立ち去る。覗き穴は開いたままなので、去っていくのが見える。
   - 「必ず OUT」だった演出が 30% で外れることになるので、怖さの効き方は実機で確かめたい。
3. **扉の前で入らない時は、見た目も音も「立ち止まる」だけ**になった。
   - 覗き穴を見ていなければ、プレイヤーには何も起きなかったように見える(足音が止まって、また遠ざかる)。
   - 物足りなければ、P4c の音の再選択で「扉の前の息遣い」等を足すのが候補。
4. **クローゼットの隙間からは、去っていく姿はほぼ見えない**。
   - 隙間の視野が狭く、振り向いて歩き出すとすぐ外れる(`c3` が暗いのはそのため)。
   - 出てきて扉が閉まっているのを見て、去ったと分かる(`c4`)。
   - 「手を掛けたまま」は取っ手の音(P4b でなし)と立ち止まりだけ。折戸をわずかに引いて戻す等の動きは入れていない(案として残す)。
5. **猶予 10 秒**:目安 8〜12 の中ほど。扉の前で立ち止まって去る場合は、忘れた時から数える(管理人はすぐ扉から離れる)。
6. **従来のテストは確率を 1/1 に固定**した。
   - 対象:`?test=enemy` 1〜24(`W.reset`)と `?test=rooms` 3 番(`hideAndWait`)。これらは「知っている部屋には必ず入る・必ず開ける」前提で書いてある。
   - 確率は 25〜35 番で見る。
   - 本番は既定の 0.7/0.5 で動く(テストだけの固定)。
7. 物語用の 221/609・6F のロッカー演出(`lockerBurst`・`AI.reveal`・APPEAR)と、EV の待ち伏せは確率の対象外。触っていない(story 19/19・spaces 16/16 で確認)。
8. コミットの共著行は指示どおり「Claude Fable 5.1」。
