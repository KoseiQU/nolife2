# P5b-5b ハンマーが体の前で交差する修正 — 引き継ぎメモ

## 1. 原因（測って分かったこと）
- 見立ては「手首が内へ回って柄が横切る」だったが、測ると原因はもう 1 つあった。**腕そのものが交差している**。
  - 各フレームで、右手の握りの点と左手の握りの点の横位置（骨盤の正中から体の右へ +、m）を比べた。右の拳が左の拳より左にあるフレーム：look_idle 191/191、walk_standard 38/38、walk_hurried 27/27、door_open_in 52/192（攻撃の 2 本は振りの最中なので除く）。
  - look_idle の右の拳は正中から −0.20〜+0.11m、左の拳は +0.01〜+0.21m。腹の前で両腕が X 字に重なっている。大柄な体に Mixamo の腕を移した結果、手が腹の前の中央へ寄っている。
  - P5b-5 の look_idle の写真で「柄が左脇へ伸びて懐中電灯と交差」して見えたのは、この腕の交差と柄の向き（上・左）が重なったため。
- 手首について。柄の向き（握り→頭＝小指→人差し指の向き）を体の座標（右・前・上）で見ると、全 14 本でほぼ上を向いていた（上向き成分 +0.5〜+1.0）。肘が 41〜145° 曲がって前腕が前へ出ているので、親指が上を向いたままでは柄が立つ。前腕が内へ回ると、柄の頭が正中を越えて左へ倒れる。
- 手首の回転だけでは「右脚の外側に沿って垂れる」にはできない。肘が曲がって前腕が前に出ている姿勢で柄を下へ向けるには、前腕を 180° 近く回す必要がある（回内外の可動域は約 ±80°）。拳の位置も正中より左のままになる。そこで、腕の交差をほどく補正（肩）と、手が胸の前に上がったままのクリップで肘を開く補正を加えた（§2 の (a)(b)）。

## 2. 直し方（`tools/blender/mixamo_merge.py` の 6b、`hammer_fix_all`）
アニメの FBX を読み込んだ直後、指の固定ポーズを焼く前に、全 14 アクションの各フレームへ回転キー（LINEAR、四元数の符号はそろえる）を焼き直す。補正するのは右肩・左肩・右肘（前腕）・右手首だけ。指は手の骨の子なので、補正後もそのまま付いてくる。

**重み w（0〜1、元のクリップで決める）**：基本は 1。下の場面は 0 にする。
- attack_*：左手が柄に掛かっているフレーム（左手の握りと柄の線分の距離が 7cm で 0、12cm で 1）、手が胸より上のフレーム（Spine2 の高さ −5cm で 0、−25cm で 1）
- door_open_in：取っ手を掴んで押し開ける区間（クリップ長の 0.25〜0.51＝f49〜98）は 0。前後はクリップ長の 0.08 かけてなだらかに 1 に戻す
- 補正量はすべて w 倍してから焼く

**(a) 肘を開く**（`elbow_max`。今は walk_oldman だけ 95°）：右肘の曲げ角 el（上腕と前腕の向きのなす角）が el_max を超える分を、肘の曲げ軸 k = 上腕 × 前腕 のまわりで前腕の骨を −(el − el_max)·w 回して開く。walk_oldman は肘が 142〜145° 曲がって拳が胸の前にあり、柄が顔の前に立っていた。最大 50° 開いて拳を腰の高さへ下ろした。

**(b) 腕の交差をほどく**（`arm_sep_solve`）：左右の上腕（Arm）を、肩を中心に「外転（体の前後軸 F まわり）a」と「外旋（上腕の軸まわり）e」で回す。格子は a −10〜50°（3° 刻み）、e −20〜60°（4° 刻み）。符号は、その向きに少し回すと握りが外へ動く方を + にとる。最小にするコスト：
```
1e-4·(a² + e²)                          補正量（度²）
+ 2e-3·|(a,e) − 前フレーム|²              時間方向（ループする歩き・走りは 2 周回して継ぎ目をそろえる）
+ 300·max(0, need − 握りの横位置)²        右 need = r_lat 0.14m、左は −0.06m より左
+ 300·max(0, 肘の張り出し − 0.16)²        肘が肩より外へ 16cm 以上張り出すのを罰する
```
**(c) 手首**（`hammer_fix_solve`）：右手に「前腕まわりのひねり Δs」と「掌の法線まわりの尺屈 Δu」を足す（C = R(前腕, Δs)·R(掌の法線, Δu)、手首を中心に回す）。格子は Δs −90〜90°、Δu −30〜60°（5° 刻み）。最小にするコスト：
```
∠(柄, target)²  target = 体の(右, 前, 上) = (0.12, 0.60, −0.80)（右脚の外側、前へ、下へ）
+ 5e-5·(Δs² + Δu²) + 2e-3·|(Δs,Δu) − 前フレーム|²
+ 200·max(0, 0.06 − 頭の中心の横位置)²     骨盤と胸(左右の肩)の正中のうち厳しい方。頭の中心 = 握り + 柄の向き·0.30m
+ 200·max(0, 0.15 − 左手の握りと柄の線分の距離)²
+ 5·max(0, |柄の右向き成分| − 0.45)²       柄が真横へ突き出す向きを避ける
+ 1000·(絶対範囲の外)                      回外 s ∈ [−15, 50]°・尺屈 u ∈ [−10, 40]°（元が範囲外ならその値までは許す）
```
- 回外 s：前腕の軸まわりに、「中立の親指の向き n0」から柄（前腕に直交する成分）までの角。親指が外へ向く向きを + とする。n0 は、肘が曲がっていれば 肘の曲げ軸 × 前腕（親指が上）、肘が伸びていれば体の前（親指が前）。肘の角 10〜30° の間でなだらかに切り替える。
- 尺屈 u = asin(柄 · 前腕の向き)。頭が指先側へ垂れる向きを + とする。
- ひねり Δs は前腕の骨と手の骨で半分ずつ受け持つ（`twist_forearm`=0.5。手首だけをねじらない）。尺屈は手の骨だけ。
- 骨の局所回転の求め方：骨のアーマチュア空間の回転を M、局所回転を L、足したい回転（アーマチュア空間）を C とすると L' = L·M⁻¹·C·M。手の骨は、親の前腕が先に C_f だけ回っているので L_h' = L_h·M_h⁻¹·C_f⁻¹·C·M_h。

**ハンマーの meta は変えていない**：`07_rigged_meta.json` は P5b-5 と完全に同じ（hammer の position_m・quaternion、flashlight_grip とも）。`src/enemy.js` は変更していない。

## 6. 判断と申し送り（ユーザー判断待ち）
- **補正の範囲を手首より広げた**。手首と前腕のひねりだけでは交差が直らない（腕自体が交差している）。そこで肩（左右の上腕の外転・外旋）と、walk_oldman の右肘も回した。歩きと見回しの腕の形は少し変わり、両腕がやや外に開いて手が体の両脇に寄る。
- **312 の立ち姿勢**（look_idle の最初のフレーム）も変わった。右腕は体の右に下ろし、柄は脚の外側の前で前下がりになる。左手（懐中電灯）は体の左。肘の曲がりはクリップのまま。P5b-5 で保留していた「腕を下ろす案」の一部に当たる。
- walk_oldman の肘を開いた（最大 50°）ので、巡回の歩き方の印象が少し変わる。拳を胸の前に上げた「老人のすり足」から、右手を下げた形になる。元へ戻すなら `HAMMER_FIX['elbow_max']` から walk_oldman を外す。
- 手が胸より上のクリップ（walk_careful・look_nervous・react_surprised・run_intent）は、柄が垂れずに立つか前・右を向く。ゲームで使っているのは look_nervous（410 前）・react_surprised・run_intent（追跡）。垂らすには肘を開く必要がある。`elbow_max` に足せば同じ仕組みで開けるが、動きの性格が変わるので今回は見送った。
- 左腕も交差をほどくために外へ開いた（look_idle・walk_standard・walk_hurried・door）。懐中電灯の光の出どころは、そのぶん体の左へ寄る。光の向きは enemy.js の従来どおり進行方向。
- door_open_in の押し開け直後（f98〜112）は、補正の重みが戻る途中で、柄がわずかに正中を越える（最小 −0.08m）。
