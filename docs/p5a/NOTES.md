# P5a 管理人の行動システム — 引き継ぎメモ

契約は DESIGN §3.8 A・B・C・E・F（物語に依らない部分）と §7 の P5a 行。D（221・105 などの特別演出）は P5b なので作っていない。
GLB の再ビルド・再ベイクはしていない（壊れた扉・扉の下の帯・奥の闇の箱・窓越しの管理人はすべて実行時のメッシュ）。`data/building.json` も無変更。

## 2. 状態機械の変更点

- **施錠の撤去**: L キーは何もしない。`_doorEntry` の鍵束→錠の段取り、スコープ演出の鍵束→錠を削除（スコープは「ノブに手を掛ける音 → 0.6 秒 → 扉を開ける」＝イベント `scope_knob`）。扉は普通に `door_open_in` で開けて入る。地下の鉄扉・空室・物語の部屋・正面玄関の `locked` などゲーム側の固定の施錠はそのまま
- **LURK の主形態 = 空室**（`lurkMode: 'room'`）。`_lurk` が潜伏先を選ぶ: 階は重み付き乱数、その階で 0.8 の確率で空室（壊れていない・閉まっている・プレイヤーから 5m 以上）、残りは廊下の角・EV の死角（`hideSpots` のうち `area: 'C'`）。入れる部屋の中の隠れ場所（`r410_back` など）は自動では選ばない（`setState('LURK', { spot })` で明示すれば従来どおり）
  - 向かう: 点灯して歩き（巡回と同じに見つける＝見られたら CHASE）、扉の前で扉を開けて（ラッチ音）0.5m 奥へ入り、中から閉める
  - 中: `concealed = true`（描かない・当たりなし・足音も鼻歌もなし）。扉の前の帯の判定は `_roomLurkTick`（下の表）
  - 点灯で通過 → `_burst(lit)`: 扉を壊す（`breakDoor`・破壊音）→ ViewLock（引き継ぎ用）→ 4.2 m/s でプレイヤーへ 1.1m まで詰める → ATTACK（`onAttackStart` で ViewLock を襲撃ムービーへ引き継ぐ）→ OUT。しゃがみも隠れ場所も救済しない
  - 消灯で通過して 4〜6m 離れた → `_burst(dark)`: 扉を壊す → 戸口から 0.9m 出て点灯し、プレイヤーへ向き直る。ViewLock 1.5 秒（向く 0.28 秒・戻す 0.32 秒）→ 0.3 秒後に CHASE
  - 静かな解除 → `_roomRelease`: 扉を開けて（ラッチ）出て、扉の方へ向き直って閉める（ラッチ）→ PATROL。壊さない・破壊音なし
- **EVAMBUSH**（新しい状態）: EV の賭け。姿を消してカゴに乗っていることにし、カゴが呼ばれた階に着いて開き始めたらカゴの中に現れる。開き切った時、プレイヤーが同じ階で戸口から 3m 以内なら ViewLock → カゴの戸口を抜けてから詰める → ATTACK、離れていれば CHASE
- **階の移動は EV だけ**: `_route` の階段の辺（外階段・北階段）の費用を ∞ にした。管理人が北階段の 1F（歩いて行けない点）や外階段の踊り場へ行くことはない。プレイヤーが階段で逃げると、管理人は EV で回り込む（階段は強い逃げ道になる）
- **遭遇**（監督役の基準）: CHASE の開始・ATTACK・SCOPE・LOCKER・飛び出し・EV の賭けで `lastEncounter` を更新（イベント `encounter`）
- **巡回の長さ**: 20〜40 秒 ×（静か 1.3／緊張 0.5）。その後 LURK
- **復帰（`reset`）**: 開けかけの空室の扉は閉める、潜伏・EV の賭けの途中の状態を片付ける。壊れた扉は残す

## 3. 判定の帯と距離（`AI.roomLurk`）

| 項目 | 値 | 意味 |
|---|---|---|
| `band.half` | 1.2 m | 扉の中心から扉の幅方向に ±1.2m |
| `band.depth` | 0〜2.8 m | 扉面から廊下側への距離（廊下の幅いっぱい。EV ホール前でも入る） |
| 通過 | 帯に入って、出た時 | 同じ側へ戻っても「前を通った」。点灯は帯の中で一度でも点けていれば点灯扱い（出た瞬間に点けても点灯） |
| `darkBurst` | 4〜6 m（乱数） | 消灯で通過 → 扉の中心からこの距離に離れた時に飛び出す。別の階へ移ったら取り消し |
| `releaseAfter` | 20〜60 秒（乱数） | プレイヤーが別の階にいる時間がこれに達したら静かに出る。戻ってきたら数え直し |
| `maxSameLevel` | 240 秒 | 同じ階にいても通過がないままこれだけ経つと静かに出る（ずっとは潜まない。契約外の上限） |
| `avoidNear` | 5 m | プレイヤーの目の前の空室は潜伏先に選ばない |
| `inside` | 0.5 m | 潜伏中の立ち位置（扉面から部屋の奥へ） |
| 呼吸 `breath` | 1.5 m 以内・静止 1 秒・5 秒おき・音量 0.16・こもり 900 Hz | 扉の前で立ち止まると扉越しに小さく |
| 飛び出し（点灯） | 4.2 m/s で 1.1 m まで詰める | その後 ATTACK（命中 1.9m） |
| 飛び出し（消灯） | 戸口から 0.9 m、視点固定 1.5 秒、追い始めまで +0.3 秒 | 追跡開始時の距離 ≈5m（テスト 5.2m）。走り 3.6 m/s ＞ 追跡 3.2 m/s で、消灯なら 5m 先は見えない→6 秒で見失う |
| 扉を開ける角度 | 1.15 rad | 管理人が出入りする時 |
| 壊れた扉 | 1.18 rad 開いて、板の面の法線まわりに 0.075 rad 傾き 2.5cm 沈む | 当たりは開いた扱い。戸口から 1.2m より奥と戸口の左右には入れない当たり（`brokenDoorBlockers`） |

## 4. 監督役（`AI.director`）と行き先の階

各階の重み（1〜7F）= base 1.0 ＋ プレイヤーの階 +6.0 ／ 隣接階 +2.5 ＋ 音の履歴（聞いた大きさ ×2.0、上限 4.0、半減期 90 秒）。段階で倍率を掛け、同じ階で 2 回続けて潜んだら、その階（管理人が今いる階）は 0。

| 段階 | 条件（直近の遭遇から） | プレイヤーの階 | 隣接階 | 巡回の長さ | 空室の選び方 |
|---|---|---|---|---|---|
| calm（静か） | 90 秒未満 | ×0.3 | ×0.7 | ×1.3 | ランダム |
| normal | 90〜240 秒 | ×1 | ×1 | ×1 | ランダム |
| tense（緊張） | 240 秒超 | ×2.5 | ×1.3 | ×0.5 | プレイヤーに近い 3 室から（同じ階の時） |

テストの抽選 1000 回（プレイヤー 4F・管理人 2F）: normal で 4F が 525 回（最頻。3F 144・5F 157・他 41〜50）、calm で 253 回に減り、tense で 669 回に増え、6F の音の履歴（3.0）で 6F が 41→228 回に増え、4F に 2 回続けて潜んだ管理人は 4F を選ばない（0 回）。
敷地・地下にいるプレイヤーは 1F、屋上B は 7F として数える。

## 5. 音の階またぎ（`AI.floorHear`）

聞こえた大きさ = loud × att[階差]。`att = [1, 0.5, 0.22, 0]`、`loud = { run 1.0, fall 1.0, crash 2.0, door 0.45, window 0.3 }`、閾値 0.4、向かうのは 25 秒に 1 回まで。

- 1 階差: 走る・落ちる物 → 0.5 で来る。扉の開閉 0.225・窓 0.15 は来ない（履歴にだけ加算）
- 2 階差: 落ちる物 0.22 → 来ない（履歴だけ）。扉の破壊 0.44 → 来る（管理人自身の音なので実際には使わない）
- 走る音はプレイヤーが別の階で走っている間 1.5 秒おきに 1 回として数える
- 向かう: PATROL/ALERT/LURK（向かう途中・廊下の角）なら `lastKnown = その階の音の位置` で ALERT（EV で移る）。空室の中に潜んでいれば静かに出てから向かう。CHASE・ATTACK・演出中は無視
- プレイヤーが聞く破壊音: 同じ階は音量 1.0・基準距離 9m（階の端まで届く）、1 階差 0.32・こもり 700Hz、2 階差 0.1・380Hz、3 階以上は鳴らさない。飛び出しはプレイヤーが同じ階にいる時に起きるので、上下の階で聞く場面は少ない（仕組みは入れた）

## 6. EV の賭け（`AI.evGamble`）

| 項目 | 値 |
|---|---|
| T | 25 秒（管理人を乗せたカゴが止まってから。`elevator.npcStop`） |
| 条件 | プレイヤーが呼びボタンで呼んだ（カゴが別の階）・カゴはまだ管理人を降ろした階にいる・管理人もその階で追跡/演出中でない |
| チャイム → 扉が開き始める | 0.3 秒（`EV.chimeLead`。全ての到着で同じ＝乗っているかは見た目でも音でも分からない） |
| チャイム → 開き切る | 1.8 秒（テスト 1.83 秒） |
| 襲撃の距離 | 開き切った時、カゴの戸口の中心から 3m 以内 |
| 詰める速さ | 4.0 m/s（カゴの戸口を抜けてから） |

- 管理人が乗っているカゴが呼ばれていないのに動く（表示が変わる・チャイム）のは従来どおり。T を過ぎていれば空のカゴが来る
- 賭けで着いた時は同階表示を出さない（扉が開く前に「同じ階」と出ると賭けにならないため）

## 7. 同階表示・ガタガタ扉・窓越しの管理人・チュートリアル

- **同階表示**: 管理人が EV で降りた階（`onArrive`）がプレイヤーの階なら、画面上部に「管理人が同じ階で「プレイヤー」をさがしている。。。」を 3 秒。着くたびに新しい滞在なので、同じ滞在中に二度は出ない。プレイヤーが管理人のいる階へ移った時・復帰の時は出さない
- **ガタガタ扉**（`DOORFX.rattle`）: 最初は 90〜160 秒後、以後 150〜300 秒おき。プレイヤーの階で 4〜15m の空室の扉（壊れていない・潜伏中でない）を 3〜5 秒。2 Hz の波の中に 11〜15 Hz の震えで、掛け金の遊びの分だけ部屋側へ跳ねる（最大 約 0.03 rad・数 mm）。音は重い連打＋ノブの金属音（はっきり・基準距離 3m）。扉は開かない・当たりは閉じたまま・管理人は出てこない。追跡中・演出中は起こさない
- **静かな予兆との違い**: 予兆は扉の下の隙間の明るさがゆっくり揺らぐだけ（`stripLeak` 線形 0.03 まで、2.5 秒で現れる）＋静止した時だけの小さな呼吸。ガタガタは扉板そのものが激しく動いて大きく鳴る
- **扉の下の帯**: 空室 73 室すべてに 1.2cm の暗い帯（ふだんは真っ暗＝扉の下の隙間）。潜伏中の部屋だけ、中の弱い明かりを何かが遮っては離れるように揺らぐ。扉が開いている間・壊れた扉では隠す
- **窓越しの管理人**（`WATCHER`）: 最初は 4〜7 分後、以後 5〜10 分おき。条件 = 本体が別の階（または EV の中）・監督役が tense でない・管理人が追跡/警戒/演出中でない・プレイヤーが窓の室内側の近く（廊下端の窓は 10m 以内、掃き出し窓は部屋の中）。窓の室内側 0.35m・目線 1.62m から立ち位置の頭と胴が窓の開口を通り、窓ガラス・格子の手すり以外に遮られない所（レイキャスト、結果は覚える）。立ち位置が視野に入っていない時に置く（目の前に湧かない）
  - 消える: 3 秒見続ける（`stared`）/0.25 秒以上見た後に視野から外す（`looked_away`）/見られないまま 60 秒/窓から離れた
  - 立ち位置 13 か所（`WATCH_SPOTS`: 駐車場・東の通路・照明柱の灯りの溜まり・東の柵・正面・北の外構・外階段の西）。調べた結果、見通せるのは **2〜6F の東端の廊下の窓、210・313・410・506・603 の掃き出し窓**。南向き・西向き・北向きの部屋と北端の廊下の窓からは手すり・庇・地形で見下ろせない。外階段の踊り場は見える窓が無いので立ち位置に入れていない
  - 見た目: 本体のモデルを `SkeletonUtils.clone`（懐中電灯は外す・ハンマーは持つ）、`look_idle` を 0.22 倍速、体をこちらへ向け首と頭で最大 0.55 rad 見上げる。光は自前の uniform（近くの照明柱の位置に 5.0・8m）。屋内の濃い霧は掛けない
- **チュートリアル**（仮文。`HUD_TEXT.tutorial` 5 枚: 管理人／潜む／エレベーター／音／賭け）: 読み込み直後に毎回。クリック・Esc・Enter・Space で次へ、最後で閉じて「クリックで開始」へ。表示中はゲームの時間を止める。`?notutorial`・`?tour`・`?test=…` では出さない

## 8. 扉の描画（性能）

空室の扉板はアニメのために結合から外したが、そのままだと 4F の描画コールが 395 → 511（影・GTAO の走査込みで +116）。止まっている扉板は階ごとに材質単位（木・レバー・号室プレートの 3 つ）で結合し、動いている扉（管理人の出入り・ガタガタ・壊れた・ノブを試した 0.25 秒）だけ別ノードを見せる → +14（結合 3 ＋帯 1 の各パス）。状態が変わった階だけ作り直す（数 ms・まれ）。

## 13. 判断に迷った点

1. **「前を通った」の判定**: 帯に入って出たら、同じ側へ引き返しても通過とした（扉の前まで来て戻るのも「前を通った」）。点灯は帯の中で一度でも点けていれば点灯扱い（帯の中で消しても逃げられない）。帯の中で立ち止まっている間は飛び出さない（出た瞬間に判定）
2. **消灯での飛び出しも扉を壊す**: 契約の「飛び出し時に大きな破壊音・扉は壊れたまま」を点灯/消灯の両方に適用した。壊さないのは静かな解除だけ
3. **同じ階にいても 240 秒で静かに出る**（`maxSameLevel`）: 契約は「階を移ったら」だけだが、同じ階に居続けると永久に潜むため上限を足した。不要なら大きくする
4. **壊れた扉の奥**: 空室には内装が無いので、戸口の奥 1.25m に暗い箱を置き、1.2m より奥と戸口の左右には入れない当たりにした（「通れる」= 戸口に踏み込める）。部屋に入れる必要が出たら P5b で内装を足す
5. **扉の下の帯は 73 室すべてに常設**: ふだんは真っ暗な 1.2cm の隙間なので P3 の廊下の見た目がわずかに変わる（扉の下に黒い線）。揺らぎの強さ `DOORFX.stripLeak`（線形 0.03）は「しゃがんで扉の下を見れば分かる・歩いていると気付かない」に合わせた。目視で強弱を決めてほしい
6. **チャイムから扉が開くまで 0.3 秒の間を全ての到着に入れた**（乗っているかどうかで見え方を変えない）。全ての EV の到着が 0.3 秒遅くなった
7. **EV の賭けの到着では同階表示を出さない**（扉が開く前に表示が出ると中にいると分かってしまう）
8. **窓越しの管理人の「静かな時間帯」**: 監督役が tense でなく、管理人が追跡・警戒・演出中でない時、と解釈した（calm だけだと遭遇直後の 90 秒しか出られない）。見通せる窓が東向きに偏る（§7）。南の部屋・北の廊下の窓からも見せたいなら、立ち位置を手すりより遠く（敷地の外）に置く必要がある＝管理人が敷地の外に立つことになるので保留
9. **入れる部屋の中の隠れ場所は自動の潜伏先から外した**（契約「潜むのは空の施錠された部屋のみ（基本）」）。廊下の角・EV の死角だけを少数派（2 割）に残した
10. **管理人は階段を使わない → プレイヤーは階段で逃げると強い**: 追跡中に別の階へ逃げると、管理人は EV で回り込む（数十秒かかる）。契約どおりだが、P5b の追跡場面（705 から 1F へ）では EV が来ない設定と合わせて調整が要る
11. **別の階の走る音でよく来る**: 隣の階で走るたびに（25 秒に 1 回まで）来る。うるさければ `floorHear.loud.run` を 0.8 以下にする（1 階差で 0.4 未満になり来なくなる）か `cooldown` を延ばす
12. **管理人の足音は別の階でも鳴る**（既存の仕組み。P4 で階差の減衰を足すとよい）
13. **チュートリアル表示中は時間を止める**: 契約に記載は無いが、読んでいる間に管理人が動くのは理不尽なので止めた
14. **視点の強制は向きだけ**: 位置は動かさない（点灯の飛び出しは向いた後すぐに襲撃ムービーが位置を寄せる）。消灯の 1.5 秒は向いて・止めて・戻すだけ

## 14. 監査の差し戻し対応（2026-11-01）

1. **消灯の飛び出しから逃げ切れない場合があった**（`?test=enemy` 13 番、飛び出しが 4.4m の時）: 4m 前後で飛び出すと追跡の最初の 2 秒は見えていて（消灯・移動中の視認 5m の内側）、廊下の突き当たりまでに見失わせられなかった。対応:

2. **`?test=building` 10 番 4F の窓の 1 フレームが 20.8ms**: P5a 前（`34fec7c` を `git archive` で別ディレクトリへ出し、別ポートで配信）と同じ条件（内蔵ブラウザ・描画 1539×1346・4F 東端の窓/北端の窓の前・管理人を EV ホールに表示）で 40 フレームの中央値を 6 回ずつ比べた:
