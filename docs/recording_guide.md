# 録音ガイド(管理人の声)

管理人の声は、あなたの録音でゲームに入れます。今は機械の仮声が鳴っているので、録った分だけ順に置き換わります。全部録らなくても遊べます。まず①の 5 本だけでも、ゲームの印象が大きく変わります。

台詞は仮案です。言い回しは自由に変えてかまいません。変えたら `docs/lines.md` の台詞を直してください(ID は変えません)。

## 録る台詞(優先順)

「声の方向」は、管理人がその声をどんな気持ちで出しているかの目安です。長さは、録音した状態でのおおよその目安です(前後の無音は取り込み時に自動で詰めます)。

### ① 今ゲームで鳴っている 5 本(最優先)

- 扉の向こうの 3 本は、管理人が潜んでいる部屋の扉の前で立ち止まると、順番に聞こえます。
- 叫びの 2 本は、105 の追跡が始まる時と、B1 から戻る時の遠い悲鳴で鳴ります。

## 録り方

- **静かな部屋**で録ります。エアコン・冷蔵庫・換気扇は止めます。カーテンや布団のある部屋だと、響きが少なくてきれいに録れます。
- **口から 20〜30cm** に iPhone を持ちます。囁きや小声の台詞は、少しだけ近く(15〜20cm)でもかまいません。息が直接マイクに当たると「ボッ」という音が入るので、口の正面を少し外します。
- iPhone の**ボイスメモ**でかまいません。
- **加工しない素の声**で録ります。エコーも、声を低くするのも、ゲーム側で掛けます。
- **普通の速さ**で話してかまいません。録音した声は、ゲーム側でごく軽く加工します(既定はわずかに低く 0.9 倍。試聴盤の「録音の聞こえ方」で、素のまま／軽い加工／強い加工を選べます)。ただし**叫びは本気で**出してください。叫びは声が割れやすいので、ふつうより少し離して録ります。
- **1 本ずつ別のファイル**にします(1 つの録音に複数の台詞を入れない)。
- テイクは何回録ってもかまいません。**一番よいもの 1 つ**を、ID の名前にして置きます。

## 置き場所と取り込み

1. ボイスメモで共有(AirDrop など)して、Mac の `assets/audio/rec_in/` に置きます。フォルダが無ければ作ってください。
2. ファイル名の先頭を台詞の ID にします。後ろに何か付いていてもかまいません。
   - 例: `mgr_line_found_01.m4a`、`mgr_line_found_01 取り直し.m4a`、`mgr_scream_01_take2.wav`
   - m4a・wav・aiff・caf・mp3 が使えます。
3. リポジトリの直下で次を実行します。

   ```
   bash tools/import_rec.sh
   ```

   ファイルごとに「何秒を何秒に詰めたか」が出ます。音が小さい・割れている場合、ID が台詞表に無い場合は警告が出ます。特定の ID だけなら `bash tools/import_rec.sh mgr_scream_01` のように指定できます。
4. ゲームを再読み込みします(Cmd+Shift+R)。
5. 試聴盤(`samples/sound.html`)でも、同じ ID の候補が録音の声に変わっているので、加工後の聞こえ方を確認できます。

同じ ID を取り直した時は、もう一度ファイルを置いて(古い方は消してかまいません)実行すれば上書きされます。`rec_in/` の元ファイルは git に入りません。取り込んだ ID は記録され、仮声を作り直す `tools/make_tts.sh` が録音を上書きすることはありません。

## 録音のあと

- ①の 5 本は、取り込めばそのままゲームで鳴ります。
- ②の声の場面(管理人の気配・目の前・襲撃の叫び・ロッカーの飛び出し)は、現在「なし」で無音です。録音が揃ったら、こちらで場面に接続し直します(フェーズ P4e)。そのとき、録音の長さや声の高さに合わせて加工の数値も調整します。
- 聞いてみて、低さ・こもり・音量が合っていなければ教えてください。ゲーム側の加工の数字を直します。取り込んだ録音は、試聴盤の「録音の聞こえ方」の節に自動で並びます(A 素のまま／B 軽い加工／C 強い加工)。
