# P4a 音の一覧(場面 × 候補 3)

`samples/sound_lib.js` の `SCENES` から生成(69 場面・207 候補)。並びはゲームの流れの順。ユーザーの選択は `samples/sound_choice.json`(`{ 場面 ID: "a"|"b"|"c" }`)。

- **書き出し名(案)**: P4b で `renderCandidate()` → `encodeWav()` した 1 本を `assets/audio/<フォルダ>/<場面 ID>_01.wav` に置く案(48kHz・16bit・モノラル・正規化済み)。足音のように同じ音を何本か揃える場面は、同じ関数の種違い(`_01〜_04`)で書き出す。
- **呼び出し元**: その音を鳴らす(または P4b で鳴らす予定の)ファイルと関数。「新設」は今は音が無く、P4b で接続口を足す場所。
- **今の仮音**: 各 NOTES(p2b・p3a・p3b・p5a・p5b1・p5b1b・p5b2a・p5b2b)と src のコメントにある仮音の名前。P4b でこの名前の合成を外し、選ばれた .wav に差し替える。
- 種別: 効果音(ピーク −6dBFS・RMS 上限 −18)／環境(ループ。RMS 上限 −26)／静けさ(ピーク −20dBFS)。ゲーム内の最終音量は P4b の接続側で決める。
- 履歴(P4a-2・2026-11-01):ユーザー回答の「作り直し」で `pl_step_corridor`(旧 A 柔らかいゴム底/B 硬い踵/C 擦り)と `room_fall`(旧 A 高い陶器/B 厚いガラス/C 転がってから割れる)の候補を作り直し、旧候補は消した。しゃがみの廃止で `pl_crouch` は使わない。選択の形式は `{ "_note", "choices": { 場面 ID: { "pick": "A"|"B"|"C"|"none"|"redo", "note"? } } }` に変わった(試聴盤から自動保存)。
