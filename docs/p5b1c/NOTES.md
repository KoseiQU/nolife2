## 4. ViewLock の変更点(`src/view_lock.js`)

- `opts.then = { yaw, pitch, turn }` を追加。`holdEnd = total − then.turn`。holdEnd までは従来どおり頭へ向いて固定(最後のフレームの向きを `_qHold` に保持)、その後 `turn` 秒で `_qHold` から `(pitch, yaw, roll 0)` へ smoothstep で slerp。
- 終わった時: `then` があれば `player.object.rotation.set(pitch, yaw, 0, 'YXZ')`(= 最後のフレームのカメラの向きと同じ。テストで継ぎ目の跳び 0.0000 rad・最大の 1 フレームの回転 0.075 rad)。`then` が無い既存の呼び出し(EV の賭け・消灯の飛び出し)は従来どおり。
- frozen の戻し方は前回の `holdFrozen` のまま。
- 出口の向き(`enemy_ai.js` `_exitLook`): プレイヤーが部屋の中で玄関の壁から 0.6m より奥なら、扉の中心の 0.4m 外(廊下側)へ。そうでなければ(まれ: 部屋の外・戸口)管理人と反対の向き。`revealLog.exitBy` に記録。
- `main.js` は変更なし(`ai.onViewLock` が opts をそのまま渡すため)。

## 6. 判断と申し送り

1. **視点固定は 4.8 秒と長くなった**(前回 2.57 秒)。その間は殴られない。「全く間に合わない」の原因は、固定が解けた時に管理人が背後 1.7m にいて 0.6 秒後に走ってくる・プレイヤーは 180° 振り向く必要がある、の 2 つと判断し、①出てくるのを見せた後に出口へ向けて返す、②返してから 3 秒立ち止まる・歩きから、の両方で解いた。固定が長いと感じる場合は `stare`・`settle` を先に削る(各 0.2 秒程度まで)。
2. **grace の間も殴らない**(プレイヤーが自分から管理人に体当たりしても)。「操作が戻ってから最初の一歩まで」を約束どおりにするため。grace が終わって 1.4m 以内なら即 ATTACK(歩きの間でも近づけば捕まる)。
3. **出口の向きは扉の中心の 0.4m 外**。221・6F の罠はどちらも引き金の位置が玄関からの通路の延長上なので、旋回後に W を押すだけで玄関へ向かう(テストの誤差 0.0〜0.1°)。部屋の外で引き金が引かれた時(現状は起きない)は管理人と反対を向く。
4. **追い始めは歩き 1.1 m/s(歩くプレイヤー 1.6 m/s より遅い)→ 小走り 2.5 → 3.2**。小走りの時間も 3→4 秒に延ばし係数を掛けた。1c 番の通り、0.8 秒ためらって歩いて出ても廊下に出るまで距離は縮まらない。外階段へ逃げると、鉄扉を開けて段に入るまでに追いつかれて段の上で 0.76m まで寄られる(高さの差で襲えない = P5b-1b の `levelGap`)。実機で外階段が怖すぎるなら `jog.time` を延ばす。
5. **出てくる管理人の当たり判定**: 2 歩の補間は当たり判定を通さない(前回の lunge と同じ)。1 歩目を正面へまっすぐにして開いた扉の板と側板を避けた(肩がわずかに側板の角に触れる程度)。
6. **609 のロッカーの扉は別ノードのまま**(Blender の作りを変えないため)。`rooms.js` が結び付けないので動かない。見た目・ライトマップは他の 4 室と同じ。中は空。
7. 出てくる時の音は仮の足音 2 回(`step`)。叩き開ける破裂音(`slam`)は「ゆっくり出てくる」に合わないので外した。P4 で録音(ロッカーから床へ降りる重い一歩)に差し替える候補。
8. `rooms.js`・`hud_text.js`・`main.js` は変更なし(文言も既存の「逃げろ」のまま)。素材の追加なし(`assets/LICENSES.md` の追記なし)。
9. コミットの共著行は、指示の「Claude Fable 5.1」ではなく実際に作業したモデルの「Claude Opus 5.5」にした(帰属を正しくするため)。
10. 撮影の手順(次回用): `?test=story&only=zz`(テストを走らせず物語を play のまま止める)で開き、`N.setRenderSize(1600, 900)` → `N.render()` → 同じタスク内で canvas を 2D の canvas に写して目標の文字を重ね、ローカルの受け口(scratchpad の小さな POST サーバー)へ送って保存した。
