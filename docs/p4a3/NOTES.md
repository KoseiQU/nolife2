## 3. 声の作り方(仮声)
- 素材:macOS の `say` の日本語音声。Otoya はこの Mac に入っておらず Kyoko は女声なので、日本語の男声 **Grandpa**(年配の男)と **Rocko** を使った(Eddy・Reed は使っていない)。`say -v <音声> -r <速さ> -o x.aiff "台詞"` → `afconvert -f WAVE -d LEI16@22050 -c 1` で `assets/audio/tts/<ID>.wav`(22.05kHz・16bit・モノラル)。手順は `tools/make_tts.sh`(再生成用。台詞・音声・速さは `docs/lines.md` と同じ)。
- 13 本・合計 1.9MB(上限 3MB)。`tools/check_glb.mjs` の 35MB は build/ の GLB・テクスチャだけを数えるので、assets/audio は対象外。
- **台詞表は `docs/lines.md`**(ID=ファイル名・場面・台詞・声の方向・仮声の音声と速さ・ユーザー録音の差し替え先)。ユーザーの録音は同じ ID の wav で上書きするだけで全候補に効く。録音は加工せず素の声で。
- 加工(`Kit.vox`。候補ごとに変えた):
  - 管理人の声:再生速度 0.7〜0.78(低く遅く)、`jit`(音程を 20〜35 セント、毎秒 7 回ほどなめらかに揺らす=合成音声の平らさを崩す)、ローパス(扉越し 650〜1000Hz＋扉板の 220Hz の山/壁越し 650Hz/近い時 3.5〜5kHz)、軽い歪み(1.3〜2.5)、`rasp`(声でノイズを変調した囁きのかすれ)、短い残響。呟き C は素材を逆再生して意味を消した。
  - 叫び:速度 1.1〜1.4(上ずらせる)、母音の区間を `loop` で繰り返して 1.4〜2.6 秒に伸ばす、音程の曲線(駆け上がって最後に裏返って落ちる)、`jit` 50〜70 セント＋ビブラート 25〜40 セント、強い歪み(5〜8)。3 種の混ぜ方:**声そのまま強調**(二重にして太く)/**声＋ノイズ**(rasp 0.9〜1.2 で喉が裂けるかすれ)/**声を遠く反響**(ローパス 900〜1500Hz、残響 4 秒・反響 0.5 秒、ほぼ残響だけ)。enemy_scream C は 1 オクターブ下(速度 0.5)を重ねた咆哮。
- 描画の仕組み:`render` は同期のままにし、声を使う候補は `tts`(素材 ID の列)を持つ。`renderCandidate` が先に `loadTTS` で wav を fetch→decodeAudioData してから描く(試聴盤も P4b もこのまま使える)。生の AudioContext に直接組む時は `await prepare(cand)` を先に。素材の URL は `sound_lib.js` からの相対(`../assets/audio/tts/`)。

## 5. 判断と申し送り
- **仮声は配布しない**:`assets/LICENSES.md` に「macOS 付属音声による仮置き。ユーザー録音で差し替え予定」と記録し、公開版に残さない扱いにした(macOS の音声出力の再配布条件をここでは判断しない)。P4b/公開前に差し替え必須。
- 台詞の文言(「みぃつけた」「いるのは…わかってるよ」「まだ…おきてるのかい」など)は §3.8 の管理人像からの仮案。ユーザーが言い回しを変えたら `docs/lines.md` を直し、同じ ID で録る。
- `say` は「みぃつけた」を「み……つけた」と間を空けて読む(素材の 0.48〜1.14 秒が無音)。かえって怖いのでそのまま使った。ユーザー録音では自由に。
- `locker_burst` の叫びは扉の衝撃と同時(A・C)/扉より先(B)。§3.8 の「1.5 秒ほど体勢を立て直す間」と重なる演出なので、P4b で `_reveal` の emerge に繋ぐ時は飛び出しの瞬間に合わせる。
- 声の候補が選ばれたら、P4b の書き出しは `renderCandidate`→`encodeWav` で加工済みの音を焼くか、ゲーム側で `Kit.vox` 相当の加工を掛けるかを決める必要がある(ユーザー録音への差し替えを楽にするなら後者。録音が来たら焼き直すだけでよいなら前者)。メインで判断してほしい。
- 呟き(`enemy_presence`)は 2.9〜3.1 秒分の素材を 0.7〜0.78 倍で鳴らすので声の長さは約 4 秒。P4b の「PATROL 中に 6〜15 秒おき」の間欠と合わせて、同じ台詞が続かないよう複数本(ユーザー録音で増やす)にするとよい。
