## 1. タイトルのサンプル 4 案(§3.11 #1)

文字「NOLIFE」は `title.js` と同じ明朝(Hiragino Mincho ProN)・字間 0.62em・色 #a9a196 を 2D で重ねた(大きさ・位置だけ案ごと)。装飾・ロゴ風の加工はなし(読みやすくする黒い影のにじみだけ)。

撮影: 案ごとに新しいページで `?noai&notutorial`(1920×1080 を明示)→ コンソールで
```js
const m = await import('./tools/title_samples.js?v=' + Date.now());
const r = await m.shoot(window.__N2, 'A');   // r.jpeg(dataURL)・r.stats
```
`shoot(N, id, opts)` の `opts` で各値を上書きできる(`cam`・`exposure`・`time`・`turn` など。上の表の列)。撮った後は露出・霧・外観の強制・覗き穴・管理人の表情を戻すが、物語の状態は戻さないので**ページを読み直す**こと(1 ページで続けて撮っても同じ絵になることは確認済み)。1 案の撮影は外観の読み込み込みでヘッドレス 3〜7 分。

### 自己批評で直した点
- 1 巡目: A は照明柱が画面中央で眩しく管理人の影が小さく文字に隠れた → カメラを門の内側の低い位置へ、管理人を 2.3m の手前・右三分の一に、霧を 0.045→0.06。ハンマーが手の奥に隠れて「空の手」に見えた → 右半身をこちらへ向ける(+1.2 rad)とハンマーが空に抜けた。
- 1 巡目: B は管理人が魚眼の下に小さく横を向いていた(`look_idle` は体が回る)→ `walk_oldman` で止め、扉の前 0.4m・頭がレンズの正面に来る位置へ。顎の下の光 1.0 は肩が白く飛んだので 0.3。血の筋がまっすぐな線だけで描いた線に見えた → 額の上で潰れた滴と微粒から垂れる形に。中間調が 9.9% で基準に足りなかった → 露出 6.0 で 10.6%。
- 1 巡目: C は廊下の手前に灰色の平らな壁が出た(前の案で外観を読み込むと、屋内でも外観の殻が描かれる)→ 屋内の案は `exterior.force = false`。`walk_brutal` は前屈みで顔もハンマーも見えなかった → `walk_oldman` で直立、ハンマーが腰の横に見える振り。露出 3.4 では中間調 7% → 4.3。
- 1〜2 巡目: D は庇の下で背景が庇の裏になり窓明かりが無かった → 灯りの窓(`XE_WinGlow` の位置を調べた)が背に入る南面の前庭へ。正面の低い視点ではハンマーが手の奥に隠れた → 右前から。顔が空を向いた横顔だった → 首と頭をカメラへ。
- 2 巡目: A は全体が灰色に明るく「暗い中に浮かぶ」が弱い → 露出 4.2→3.7。

## 3. チュートリアルの露出(§3.11 #3)

- `src/tutorial.js`: `TUT.exposure = 3.2`。場面に入る時(`_go`)に 1〜7b は 3.2、0(黒)と 8 は開始時の値(4.5)。場面 8 の頭(暗転の中の `_restore`)と `_finish` でも開始時の値へ戻す。Esc・ポインタロック解除で飛ばすと `_go(8)` → `_restore` を通るので戻る。未読でロックが外れた時は飛ばさずに流れ続け、終わりで戻る。切り替えは場面の頭の暗転(0.6 秒)の中。

## 4. 既知の妥協点

1. **露出の中間調は画面中央 50% で測った**。画面全体だと 3.2 の時 5.8%(4.5 の時でも 17.5%)で 15% に届かない。露出だけを下げると平均輝度の比 0.6〜0.75 と全体の中間調 15% は両立しない(試した値: 環境光を 0.32→0.6 で全体の中間調 28%・比 1.35、半球光の空だけ ×1.4・地面 0 で 15%・比 0.95、自分の懐中電灯を弱く点けても 6% のまま。暗部を持ち上げると比も一緒に上がる)。既存の暗さの判定(`?test=enemy` の `centerLuma`・P2c)と同じ中央 50% に合わせた。全体で 15% が要るなら場面 1 の照明を足す別工程になる。
2. 4 案の文字は 2D で重ねた静止画(本実装では DOM か 2D キャンバス)。字形は Hiragino Mincho ProN(ヘッドレス Chrome の macOS フォント)。
3. **D の首と頭の向きは撮影用の後付け**(`headToCamera`。クリップのまま=空を向いた横顔)。D を選ぶ場合、本実装では同じ後付けか、見下ろす振り下ろしのクリップが要る。ハンマーは片手(`attack_downward`)で、頭上の両手の振りかぶり(§3.4.1)ではない。A・D ともハンマーは頭の横〜少し上の高さ。
4. A の霧(0.06)は外観・木の材質の霧だけ。`scene.fog` の外の色は main.js の定数(`FOG_OUT`)なので、本物の階の外壁(近くの 1〜3F)は元の霧のまま。A の画角では本物の階はほぼ映らない。
5. B の露出 6.0 は魚眼の外の黒(画面の 7 割)を除いた中を明るく見せるため。本編の覗き穴(4.5)より明るい。
6. B の扉の前の管理人は `walk_oldman` の 1 コマで止めた立ち姿(覗き込む専用のクリップは無い)。
7. 撮影中に P6b-E2 が階の GLB を再ベイクしていた。4 枚とも居室の家具は映っていない(B は廊下、C は廊下、A・D は外)ので影響なし。読み込みの失敗は起きなかった。
8. ヘッドレスでは 1 案 3〜7 分かかる(外観と階の読み込み・1 フレームの描画)。
