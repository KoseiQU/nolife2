## 0. 前提(実行時の光の仕組みが決める上限)

外観の材質は `src/exterior.js` が整える。**屋外にはリアルタイムの光が無い**(月明かり・空の明るさは拡散だけをシェーダで足す。照明柱の灯りの溜まりは加算の円)。
このため src を変えずにできることは次に限られる。
- 粗さは懐中電灯(プレイヤーの SpotLight)に照らされた時にしか効かない。
- metalness > 0.5 の材質だけが共通の環境(RoomEnvironment)を `LOOK.metalEnv`(0.08)で映す。金属にすると拡散(月明かり)は消え、映り込みだけで見える。
- 地面の濡れた映り込みや窓ガラスの反射は、視点で変わる鏡面としては出せない。代わりに**発光の膜**(半透明・A で下を少し消して発光を足す)で静的に近似した。
- 階の GLB(今いる階の ±1 が本物として出る)は触れない。外観の帯だけ変えると本物の階と帯で見た目が分かれるので、外の塊・手すり・隔て板・枠・格子は**全階共通の被せ物**(`ExtAlways` に置く。本物の階の同じ部品を 1cm/3mm/4mm 外から包む)にした。帯からはその部品を消した。

## 4. 自己批評と手直し(2 巡)

1 巡目(タイル・雨だれ・金属・膜を入れた直後)
1. **雨だれが縞(バーコード)に見える**: 1 階ごとに 46 本の濃い筋 → 22 本・濃さ 0.04〜0.15・半分は短く、上端の帯も弱めた
2. **格子(MX_Bars)が白い点のちらつき**: 金属にすると共通の環境の映り込みが細い格子で遠目にモアレ → 金属をやめ(metal 0)、全階共通の被せ物にして tint 2.4 で本物の階(ベイク)の明るさに寄せた
3. **手すり・枠が白く浮く**: F0 0.30/0.26 では夜の壁より明るい白線 → 0.16/0.14 に
4. **窓のカーテンが消えた**: ガラスの膜の A 0.30〜0.55 が奥を消しすぎ(ガラスの反射は 1 割前後)→ A 0.10〜0.21
5. **隔て板が暗すぎ**: tint 0.62 → 1.3(従来の 0.55 と同じ明るさ)

2 巡目(濡れの膜)
6. **水たまりが「明るい塗り」に見える**: 照明柱の光の映り込みの広がり 2.8 → 2.2m、水たまりの縁を締め、面積を 2 割弱に、空の映り込みを弱めた。膜(水たまり以外)に光だまりの広い艶を足した
7. タイルの目地の色を少し明るく(レンガに見えすぎ)

判定: 敷地の別角度(S)・地面(W)・屋上からの見下ろし(R)・懐中電灯で壁(FW)は変化が分かる。**A の構図は変化がほぼ分からない**(§6-1)。プラスチックに見える物・白く浮く物は 2 巡目で無し。

## 6. 既知の妥協点

1. **A の構図(霧 0.06・露出 3.7)では変化がほぼ見えない**: 建物まで 12〜25m、霧の覆いが壁で 40〜90%。雨だれ・タイル・手すりの金属は霧に埋もれ、地面も見える範囲(7〜15m)は灯りの溜まり(加算)と霧が主。照明柱の映り込みは鏡の位置(カメラの 1〜3m 先)が画面の外。A で効かせるには霧を下げるか、地面を画面に多く入れる構図が要る(F1 の判断)
2. **濡れた映り込みと窓の反射は静的な発光**: 視点で動かない。照明柱の映り込みは柱の足元に寄せた光だまりの艶(実物は見る人と灯具の間に縦に伸びる)。屋外にリアルタイムの光が無く src も変えないため
3. **粗さ(アスファルト 0.3・タイル・手すり 0.4)が見えるのは懐中電灯の時だけ**(同上)
4. **格子(4F 以上の縦格子)は金属にしていない**(§4-2 のちらつき)。笠木・枠・支柱(`MR_Rail`)は金属
5. **障子(MX_Alu)とガラスの膜(入れる部屋)は帯の中だけ**: 本物の階が出ている時はその階の障子は従来の塗装色、入れる部屋のガラスに膜なし(開く窓に膜を残さないため)
6. **本物の階のバルコニーに立つと手すり・隔て板は被せ物の材質**(実行時の光。ベイクの照り返しは乗らない)。被せ物は 3mm 外なので当たり判定・見た目の位置は変わらない。格子は本物の階の物が 4mm 手前に来るのでバルコニーの中からは従来の見え方
7. **外壁の写真は無地の吹付け**(ref の exterior_day)だが、契約どおりタイル(二丁掛 227×60mm・目地 6mm)にした。目地の色を地に近づけて遠目は灰色がかったベージュの無地に見えるようにした
8. **A の霧の色の不一致(既存)**: title_samples の A は `LOOK.ext.fogColor` を明るい色にするが、`scene.fog` の色は main.js の既定のまま。本物の階(scene.fog)と外観(外の霧)で霧の色が違い、読み込み順によっては 1F・2F が暗い板に見えていた。外の塊は被せ物(外の霧)になったので壁は揃ったが、本物の階の他の部品(扉・ガラス・M_ExtWall)は暗いまま。チュートリアルの場面 1 で霧を変えるなら scene.fog の色も同じにする(F1 / main.js 側)
9. **`tools/build.sh` の外観の段は一時ファイル→mv をしない**(既存の挙動)。今回は Blender を直接 `--out build/.stage/…` で走らせて mv した(§7)

## 7. 再生成

```
python3 tools/ext_textures.py --f2        # F2 の新しいテクスチャだけ(一時ファイル→置き換え。既存の ext_* は書かない)。引数なしなら全部
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup -P tools/blender/build_exterior.py -- \
  --out build/.stage/exterior.glb --manifest build/.stage/exterior_manifest.json --inst build/.stage/exterior_instances.bin
mv build/.stage/exterior*.{glb,json,bin} build/   # (3 本を 1 本ずつ mv)
node tools/check_glb.mjs
```
調整の入口: `build_exterior.py` の `f2_materials()`(色・粗さ・tint)・`F2`(被せ物のずらし量)・`F2_SKIN`(被せる材質)、`ext_textures.py` の `make_tile_wall`(雨だれの本数・濃さ)・`make_wet`(水たまりの面積・映り込みの強さ)・`make_glass_sheen`。
