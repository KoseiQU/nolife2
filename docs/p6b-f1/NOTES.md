## 1. 実測: 灯りはどう描かれているか → 一斉に落とす最小の手段(#4・#1 共通)

| 光 | 描き方(実測) | 停電で落とす手段 |
|---|---|---|
| 常夜灯・EV ホールのダウンライト・壁付け灯・窓の空の光の照り返し | Blender で焼いたライトマップ(外殻 `floor_N_lightmap.webp`、部屋の組 `floor_N_rooms_lightmap.webp`)。材質の `lightMapIntensity` = manifest の intensity × `LOOK.lightmapGain`(外殻 1.027・部屋の組 0.12)。灯具ごとには分かれていない | 階の材質のシェーダで「ライトマップが irradiance に足した分」だけに倍率(`uN2Lm[階]`)を掛ける |
| 灯具のカバー | 発光面。1F/2F/4F/7F で実測: `M_LampCover` 6.0・`M_Downlight` 8.0・`M_BracketCover` 3.0・`M_ExitSignSq` 0.484・`MX_SecMon` 0.5・`M_StepLight` 2.2・`M_BracketDim` 1.0。**階の GLB は材質ごとに 1 メッシュに結合**(`world._merge`)されているので、1 灯だけを材質の値で消すことはできない | `totalEmissiveRadiance` に倍率(`uN2Em[階]`)。1 灯は位置の近さで落とす(下) |
| 窓の夜空・EV の表示/ボタン/カゴの天井・玄関の外の街路 | 発光面(`M_Window`・`MX_WinOut`・`M_WireGlassOut`・`M_EVDisplay`・`M_EVCarDisplay`・`M_Button`・`M_CarCeiling`・`M_Backdrop`) | 落とさない(KEEP。月明かりと動く EV) |
| 環境光の床(月明かりの下限 §3.2.1) | 半球光 `ambientFloor` 0.12 | 停電中だけ 0.5 倍(下の §4) |
| 金属・ガラスの映り込み | 共通の環境マップ(`metalEnv` 0.08 ほか) | 同じ区間で `max(倍率, 0.2)` を掛ける(真っ暗な中でノブだけ光らないように) |
| 管理人だけに効く光 | `enemy.js` のシェーダ注入。`enemy._lampAll` の色(常夜灯=暖色・非常口=緑・窓=青白) | 常夜灯と非常口の色に倍率(窓は残す)。`enemy.js` は触らず、`power.js` が色を書き換える |
| 外観 `exterior.glb` の灯り | `XE_WinGlow`・`XE_CorrLamp`・`XE_CorrDepthLit`・`XE_LobbyGlow` ほかの発光 | 全階の平均の倍率で `emissiveIntensity` を書き換える(照明柱 `XE_Lamp` は敷地の灯りなので残す) |

**最小の手段** = `src/power.js` の `powerPatch(m)` を、階の材質を整える所(`world._prepare`)で 1 回だけ差し込む。
- 頂点で `vN2W`(ワールド座標)を出し、フラグメントで `#include <lights_fragment_begin>` 直後の `irradiance`(環境光＋半球光まで)を控え、`#include <lights_fragment_end>` 直前に `irradiance = 控え + (irradiance − 控え) × n2LmGain()`。この区間で足されるのはライトマップだけ(環境の拡散は `iblIrradiance` で別)なので、懐中電灯・半球光・管理人の懐中電灯は変わらない。怖い扉の血のデカール(`N2_Blood`、ライトマップの代わりに `vLmIrr` を同じ区間で足す)も同じ式で落ちる
- 階は `vN2W.y` から(`floor((y + 0.3) / 2.9) + 1`、0 = 地下 B1・7 = 7F と屋上B)。uniform は全材質で共有(`POWER_U`。値を書くだけ = 毎フレーム数十個の数を書き換えるコスト)
- 1 灯のちらつき: `uN2Dim`(位置 xyz・強さ w)からの距離で、ライトマップは半径 4.0m(中心ほど 92% 落ちる)、発光面は半径 0.9m(灯具のカバーだけ)
- プログラムのキーは差し込みの並び(`addPatch`)。既存の差し込み(`extShade`・`corrGlass`・`specularOnlyEnv`)は前に残す。`specularOnlyEnv` は上書きしていたので `addPatch` に直した
- 後から足される血のデカールは 2 秒おきに探して差し込む(`power.scan`)

## 4. #4 本編の停電(`src/power.js`・`main.js` の配線)

| | 値 |
|---|---|
| 時計 | 1 つ(`power.t`。`step` の中で進む)。消え掛かり 60〜180 秒に 1 回、全消灯は 240〜480 秒に 1 回(次は戻ってから数える) |
| 消え掛かり | プレイヤーの階の天井灯(`M_LampCover`・`M_Downlight` の結合メッシュの頂点を 0.7m でまとめた中心 = 4F で 6 灯)のうち、プレイヤーに一番近い 1 灯。2〜4 秒、短い明滅(深さ 0.75〜1)を繰り返し、途中で一度長めに暗くなって、点いて終わる |
| 全消灯 | 最初の 0.42 秒はつっかえ(3 回瞬く)→ 全階で ライトマップ 0.03・灯具/非常口の発光 0・環境光の床 0.5 倍・管理人だけに効く常夜灯/非常口の光 0・外観の窓/廊下/ロビーの灯り 0。窓の夜空・EV の表示/ボタン/カゴの天井は残す。EV は動く。管理人の行動は変えない |
| 戻り | 45〜75 秒の終わりの 2.2 秒で、1F から順に 0.3 秒ずつずれて各階が点滅(点く 0.07・消える 0.09・点く 0.06・消える 0.18・点く)して戻る |
| 起こさない | 異空間(階キーが X)・地下 B1・死亡演出中は時計が来ても始めず 10 秒後に試し直す。タイトル・チュートリアル・エンディング(`story.ending`)では始めず、進行中なら打ち切る |
| 片付け | 時刻だけ(倍率は毎フレーム時刻から計算)。消えている間に段が進んでも・階を移っても壊れない。環境光は倍率が変わった時だけ書く(チュートリアルの環境光の持ち上げと競合しない) |
| 自動で起こす所 | 通常プレイだけ(`?tour`・`?test=…` では起こさない)。`?blackout=now`(3 秒後)/`?blackout=<秒>`・`?flicker=now|<秒>` で最初の 1 回を早める、`?power=off` で止める |

**環境光の床を 0.5 倍にした理由**: ライトマップ 0.03＋発光 0 だけだと、廊下の画面全体の輝度は平常の **0.368 倍**(半球光 0.12 が露出 4.5 で壁を照らす)で、契約の 1/5 に届かない。0.25 倍で 0.089(真っ黒で輪郭も消える)、**0.5 倍で 0.162**(輪郭がかろうじて分かる)。

## 7. 既知の妥協点

1. **場面 1 の外観は F2 の作業中の `build/exterior.glb` で撮った**。案 A で暗かった 1F〜2F の塊(車寄せ)が今は明るい灰色の平面に見える。同じ撮影ハーネス(`title_samples.js` の A)で停電の差し込みあり/なしを撮り比べて同一だったので、F1 の変更ではなく外観の差し替え中の状態。F2 の完了後に場面 1 を撮り直してほしい
2. **全消灯は環境光の床も 0.5 倍に落とす**(§4)。契約の「ライトマップ 0.03」だけでは 1/5 に届かないため。懐中電灯なしでは輪郭がかろうじて分かる暗さ(§3.2.1「暗いと見えないは別物」の下限を、45〜75 秒の間だけ下回る)。懐中電灯を点ければ通常どおり見える
3. **非常口のサインも消える**(「窓からの月明かりだけ残す」を文字どおりに)。EV の表示・ボタン・カゴの天井は「EV は動く」ので残す。外観の照明柱(敷地の灯り)も残す
4. 1 灯のちらつきは位置の近さでライトマップを落とす近似(半径 4m)。焼き込まれた隣の灯の光も、その範囲では一緒に少し暗くなる。灯具ごとのライトマップは無い(再ベイクしない方針)
5. 消え掛かりの対象は「天井の常夜灯とダウンライト」。居室の天井灯は夜は点いていない(発光していない)ので対象にならない
6. 死亡・異空間・地下は「始めない」だけで、進行中の停電はそのまま続く(建物の電気は時刻で戻る)
7. タイトルの管理人は look_idle の一部(5.3〜6.0 秒)の往復。全体を極低速で流すと体が横を向く区間に入る
8. タイトルの滴の太さは CSS px(3〜6px)。高解像度の大きな画面では相対的に細く見える
9. タイトルの全消灯は環境光 0.5 倍・露出 0.6 倍も足して「真っ黒に近い」にした(ライトマップ 0.02 と発光 0 だけでは廊下の壁が環境光で見えた)
10. 7c の露出は 6.0(案 B)。上体を寄せる演出(lean)は頭が下がるので使っていない
11. `?test=enemy` 24 番の開始状態は「EV ホールで置き直した直後の管理人」。タイトルの片付けは起動時と同じく管理人を置き直す(巡回の途中の状態までは戻さない)。実際のタイトルの開始時は第1段の「眠り」なので、片付けで眠りに戻る(`?test=tutorial` 0・2 番で確認)
12. 怖い扉の血のデカールは読み込みの後に足されるので、2 秒おきの探索で差し込む(1 回だけシェーダのコンパイルが走る)
13. コミットは項目ごと(#4 → #1 → #2・#3)。#2 と #3 は同じ `tutorial.js` なので 1 つにまとめた。#4 のコミット(6a24183)単独では main の配線が無く、#1 のコミット(ba5bc4f)の `main.js` に停電の配線も入っている
14. 60fps はヘッドレスの実ループの値(上限 60 で張り付き)。実機の目視が必要
15. 音はエージェントには聴けない。7c の打撃音の大きさ・タイミングは実機で確認してほしい
