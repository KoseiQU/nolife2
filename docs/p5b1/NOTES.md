- **P5b-2 の差し替え点**: `SPACE_DEFS` の 1 行(origin・色・`slots` = 物の置き場所)と `_build(key)` の見た目・`_collisions(S)` の当たり。`story.js` が使うのは `SPACE_DEFS[k].entry`・`exit`・`back`・`at(slot)` と `Spaces.show()`/`lampsFor()` だけ。置き場所の名前(`memo`・`key`・`desk`・`ambush`・`hook`)を残せば story.js は変えなくてよい。105 の追いかけっこ・312 の潜水と息・705 の柱の広間・B1 のループは全部ここに入る。

## 5. 221 のロッカーと 6F の罠 3 室(ワープ)

- **内装の入れ替え(`swap`)**: 221・601・606・609・611 は机とクローゼットを入れ替えた(`src/interior_layout.js`)。机の周り一式を玄関側へ 1.08m(`du = −1.08`)、クローゼットを奥(u 4.30〜5.26)へ。机の前に立ったプレイヤーと、奥のクローゼットから出る管理人の間に机が来るので、玄関へ逃げられる。`build_assert.mjs` が「机がクローゼットより玄関側」を全 5 室で確かめる。`points.desk`(机の上 = 鍵を置く所)と `points.deskFront`(机の前)を追加。
- **221**: 小さな鍵を拾った瞬間に `ai.lockerBurst('221')`。
- **6F の罠**: `STORY.trapRooms = ['601', '606', '611']`(互いに隣り合わない。西棟西列・南棟・東ブロック)。机の上の「鍵に見える物」から水平 1.2m(`trapDist`)以内に入ると発動。6F にいて第2段以降、管理人が ATTACK/DEAD でない時。1 室 1 回(`traps`)。220 の鍵の部屋は `keyRoom6F = '609'`(罠でない、南棟の東端)。
- **`enemy_ai.js` の変更点**:
  - 新しい状態 `APPEAR`。`lockerBurst(rid)` はその部屋のクローゼット(`roomsSys.closets`)の足元へ、`appear(o)` は指定の場所へ、本体の現在地と無関係に置き直す(ワープ)。クローゼットなら扉を速さ 3.5 で開け、破裂音 `slam`(音量 0.9)。
  - 流れ: 現れてこちらを向き点灯 → 視点固定(`lock`、既定 1.0 秒)→ クローゼットから通路の点 `out` へ最大 0.7 秒・1.8 m/s → 体勢を立て直す間(`recover`、既定 1.5 秒。こちらを照らして向き直る)→ CHASE。追い始めの `slow` 秒(既定 = P5a の消灯の飛び出しと同じ `darkChase.time` 3.0 秒)は 2.5 m/s、その後 3.2 m/s。走り 3.6 m/s なら逃げ切れる。
  - `setDormant(on)`: 第1段の眠り。`update` の先頭で止める。
  - `allowStairs`・`noEV`: 第9段の最終追跡だけ。階段の辺の費用 = 9 × 階差(1F の北階段は建物の外の地面なので除く)、EV の辺は ∞。§3.8 B の「EV だけ」は徘徊の規則で、追跡の台本上の例外。
  - `portals`: 移動グラフの無い階(敷地 `G`・別空間 `X…`)との出入り口。`_route` はグラフの無い階ではまっすぐ、階の間は portal を通る(無ければ空の経路 = 行かない)。B1 との間は常に空の経路(管理人は地下に来ない)。CHASE はプレイヤーが portal を抜けた時は見失わずに追い、グラフの無い階ではまっすぐ追う。PATROL はグラフの無い階なら portal から建物へ戻る。
  - 物語の施錠(`door.storyLock`)の扉は管理人も開けない(ノブを鳴らして 1.2 秒で去る `door_story_locked`)。巡回の「覗く」も物語の扉は選ばない。
  - 別空間にいるプレイヤーの階は入口の階として数える(監督役の重み)。

## 6. 第9段の最終追跡・第11段の敷地追跡とエンディング

- **第9段**: X705 で地下の鍵を拾うと `sub = 'chase'`、目標「逃げろ」、EV 無効、`allowStairs`・`noEV`、portal `X705`(X705 の出口の 0.5m 奥 ⇔ 7F の 705 の扉の前 20.85, 21.2)。0.5 秒後(`chaseAppearDelay`)に X705 の奥 `ambush`(361.45, 5.4)に現れる(視点固定 1.0 秒・間 1.5 秒)。プレイヤーが X705 の外にいれば 7F の扉の前に(0.8 秒・1.2 秒)。プレイヤーは出口へ走れば 7F の廊下へ出て、管理人も portal を抜けて追う。外階段か北階段で下り、1F か敷地に着いた時点で第10段(階段・EV の例外を戻し、portal を消す)。追跡中に死んだら `9c`(7F 16.2, 21.2・外階段の方を向く)から、2.0 秒後に 705 の扉の前に管理人。
- **第10段**: 管理人は地下に来ない(B1・XB1 への経路は空)。EV は第10段以降もプレイヤーに反応しない。
- **第11段**: 段の開始で portal `entrance`(1F 17.6, 27.5 ⇔ 敷地 17.6, 28.9)を足す。敷地に出て玄関(17.6, 28.1)から 6.0m(`siteChaseDist`)離れたら、1F ロビー(17.6, 26.7)に管理人が現れる(視点固定なし・間 0.4 秒・追い始めの 2.0 秒は 2.5 m/s)→ 玄関を抜けて敷地をまっすぐ追う(3m 以内は 1.6 m/s)。
- **エンディング**(`startEnding`、車のキーを持って黒い車に「乗る」): 管理人を眠らせ、0.6 秒で暗転 → 運転席(車 0 の rect の x + 0.55w, z + 0.72d、東向き)に座り、ダッシュボード・ハンドル・ピラーのメッシュをカメラに付ける。エンジン始動 → 2.6〜5.0 秒で後ろへ下がりながら南へ向きを変える(28.6, 3.0)→ 5.0〜10.5 秒で車路を南東の門(33.2, 33.0)へ。2.4 秒で走行音、9.0 秒から 1.2 秒で暗転、10.4 秒で「脱出した／深夜三時の学生会館から／もう一度」の画面(`hud_text.ending`)。「もう一度」は `?notutorial` で読み込み直す。分岐なし。
