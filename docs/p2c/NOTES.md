# P2c P2b差し戻し対応 — 引き継ぎメモ

## 1. 消灯時の視界（§3.2.1）
- `LOOK.lightmapGain` 1.0→1.2（常夜灯・窓明かりのベイクを少し持ち上げ）
- `LOOK.ambientFloor` 0.12：半球光（空 `ambientSky` 青灰＝月明かり、床 `ambientGround` 暖色）。410 室内はライトマップがほぼ 0 のため、これが輪郭の下限を作る。敵の材質にも効く（人影のシルエット）
- 露出は 4.5 のまま（廊下の常夜灯の見え方を P0 合格時から変えないため）
- 判定：`?test=enemy` の `8_dark_visibility`（960×540 で描いた画面中央 50% の平均輝度。しきい値 室内 0.035・廊下 0.12）

| 場面 | P2b | P2c |

| 410 室内・消灯 | 0.007 | 0.051 |
| 廊下・消灯 | 0.162 | 0.213 |

## 2. 管理人の懐中電灯と光の帯
- 点灯方針：PATROL/ALERT/CHASE は点灯、LURK は消灯、ATTACK は直前のまま（`EnemyAI.setState`）
- 同心円の帯の原因はプレイヤーの懐中電灯のクッキー（`player.js flashlightCookie` の反射鏡リング＝細い山 2 本）。管理人の光は帯なし（確認済み）。リングを幅の広いなだらかな肩 1 本に置き換えた。管理人の光も penumbra 0.45→0.75 で縁を柔らかく

## 3. LURK（潜伏）
- 隠れ場所 `HIDE_SPOTS`（enemy_ai.js、P3 で building.json へ移す前提の素朴な配列 `{id, area, x, z, faceTo}`）：`r410_back`（410 奥の角）/ `r410_door_shadow`（開いた扉板の裏）/ `corridor_north`（廊下北端の角）/ `ev_blind`（EV ホール東の死角）
- 室内の隠れ場所へは鍵で入り、プレイヤーが中にいなければ内側から扉を閉める
- 立っている間：消灯・鼻歌なし・`look_idle` を 0.25 倍速。足音は小さめ
- 発見（`AI.lurk`）：遮蔽なしで 4m 以内／同じ部屋に入る／プレイヤーの懐中電灯の円錐（判定角 0.55rad・12m）に入る → grin 0.8 → 消灯のまま `walk_brutal` 1.6m/s で無言の接近 → ATTACK。10m 以上離されるか 6 秒見失うと CHASE（点灯）
- 時間配分：LURK 60〜120 秒 → PATROL 20〜40 秒 → LURK…（巡回の予算が尽きると次の隠れ場所へ）

## 4. 室内側のドアスコープ
- `main.js buildDoorScopeInside()`：扉板（door410.node）の子に真鍮リング（金属・環境反射）＋筒＋レンズ（暗いガラス＋環境反射＋廊下の常夜灯が映った小さな発光点）。扉と一緒に回る
- 1.2m 以内で扉に正対すると画面下に「E長押し：覗く」（覗き穴の発動条件も 1.2m に揃えた）

## 5. 襲撃ムービー（`src/attack_movie.js`）
- ATTACK 開始（`EnemyAI.onAttackStart`）：入力停止、カメラをプレイヤーの頭の位置に固定し顔へ向け、0.3 秒で 0.25m 寄りつつ FOV 68→44・12cm 下げて見上げる構図。顔の前・やや下に補助光（敵の材質だけに効くシェーダ注入の 7 枠目 `enemy.faceFill`）
- ヒット（0.85 秒）：①画面の飛沫 34 個（2D キャンバスに飛跡と塊を描き、最終段の ShaderPass で合成。膜越しにわずかに歪む）②レンズを伝う滴 最大 8 本（1.0 秒で減速しながら垂れる）③3D の血煙（Points 70 粒、0.9 秒）＋カメラの沈み・傾き・揺れ。音：叫び（攻撃開始）・打撃（ヒット）を WebAudio で仮合成
- ヒット後 1.1 秒から暗転（1.75 秒で真っ黒）→「見つかった」→ 3 秒後に復帰。ATTACK 開始から暗転完了まで約 2.6 秒
- 初回発動時の引っかかり（50ms）対策として、起動時に血のパスと血煙を 1 回描いてシェーダを先にコンパイル

## 6. 血飛沫の写実化とムービー構図（監査差し戻し対応）
- 画面の血：輪郭線・艶の白点を廃止。暗い深紅（#5a0a0a〜#8a1010 相当、彩度 -18%）の縁の柔らかい半透明の斑点を冪分布で 170 個（大きいものほど少ない）＋衝撃点周りの霧吹き状の微粒 420 個＋薄い血の膜。大きな滴は楕円の重ね合わせで不規則、25% だけ短い尾（途中で途切れる）。大きめの滴から最大 9 本、細い筋が 1.4 秒かけて下へ垂れる。合成は背景を沈めてから深紅を乗せ、大きな滴の縁だけわずかに屈折
- 3D 血煙：霧状スプライト 26 枚・通常合成・暗い赤、0.3 秒で広がりながら消える
- 構図：顔を時定数 0.15 秒で追い続ける。振り下ろしに合わせ 0.55→0.85 秒で視点が 0.45m 沈み（崩れ落ちる）、前かがみの顔を下から見上げたまま血が飛ぶ
- 不具合修正：ShaderPass が uniforms を複製するため血のテクスチャ更新が届かず無表示になる場合があった→元テクスチャを差し直し。消灯時の懐中電灯レンズが暗所で白い円盤に見えた→消灯時は非表示
