# 章1〜2 演出台本（P3実装仕様）

DESIGN.md §3の章立てのうち、章1「起床」・章2「探索」の確定台本。events.js はこの台本のイベントIDを実装する。ゲーム内テキストは本書が正文（実装時に改変しない。{NAME} は開始時に入力した主人公の名前に置換。自室は **410号室** 固定）。

## 演出の原則（§6の適用）

- 放送は「毎日流れている実物」の口調を崩さない。狂っているのは時刻と内容だけ
- 字幕・モノローグは最小限。説明しない。プレイヤーに気づかせる
- 章1〜2にジャンプスケアは置かない（インターホンのモニター越しの顔はP3後半＝章3の枠）

## 章1「起床」

### EV-101: 目覚め
- トリガー: ゲーム開始（名前入力済み・自室410）
- 演出: 黒画面から3秒でフェードイン。自室のベッド脇に立った状態。室内灯は点かない（スイッチSEのみ空振り）。机の上のスマホは調べられる
- 字幕（起床直後、3秒表示）: 「……3時？」
- スマホを調べた時: 「圏外 ─ 7/5 3:00」表示のまま動かない

### EV-102: 朝食放送（開始20秒後、または自室ドアに近づいた時の早い方）
- 演出: 館内チャイム（上昇4音）→ 放送。放送中、廊下の常夜灯が一瞬明滅
- 放送文（2026-07-06 改訂：「本日も良い一日をお過ごしください」を削除）:
  > おはようございます。管理室です。
  > 朝食のご用意ができました。
  > お食事の方は、九時三十分までに食堂へお越しください。
- 放送直後、主人公のモノローグ字幕（2026-07-06 追加。深夜3時に朝の放送が流れる違和感への反応）:
  > ……なぜ、こんな深夜にアナウンスが？
- 時計と放送の矛盾を、主人公のこのつぶやきで明示的に引き立てる

### EV-103: ドア開閉音の開始（EV-102終了直後から常駐）
- 演出: 別フロアからドアの開閉音がループ開始（ガチャ……バタン。間隔12〜20秒で揺らす）。3D音響で上方向から。以後、章を通じて「何者か」のランダム周回音として鳴り続ける

### EV-104: 廊下へ出る
- トリガー: 自室ドアを開けて廊下へ
- 演出: 廊下は常夜灯のみ。遠くでEVの駆動音→「チン」。どの階かは分からない
- 目標更新: 「様子がおかしい。1階に下りてみよう」

### EV-105: 最初の「呟き」（廊下に出て30秒後）
- 演出: PA放送ではない。「何者か」の現在位置から、低く恐ろしい声が**部屋の数字だけ**を呟くのが微かに聞こえる。ポジショナル音声（遠い階なら囁き程度）。直後にガチャ…バタン
- 呟き（例。数字はその時いる部屋に追従、読みは一桁ずつ）:
  > ……に、いち、さん……
- 字幕: 聞き取れる距離（同フロアか隣接階）のみ「……に、いち、さん……」を小さく表示。遠い場合は字幕なし（何か聞こえた、で留める）
- 頻度: 以後、呟きは**数分に一度**だけ。基本の存在音はドアの開閉のみで、主人公は「何者か」の位置を掴めない
- 備考: 名前を呟く変化形は章4〜5（P5）の切り札。ここでは絶対に使わない

## 音響メモ（P3のaudio.js合成仕様）

- 館内チャイム: 上昇4音（C-E-G-C、サイン波+短いリバーブ）。実在の館内放送らしい安っぽさを保つ。**PA放送は日常系（朝食放送）のみ**
- 放送ボイス: 合成ボイスにローパス+小さなハム。聞き取れるが機械的に。全文に字幕
- **「何者か」の呟き**: PA系とは全く別の質感。低く恐ろしい声（speechSynthesisなら pitch 0.1〜0.3・rate 0.5〜0.7、または合成ウィスパー=帯域ノイズの音節変調）。ポジショナル再生・距離減衰強め。残響は廊下反響を薄く
- ドア開閉: ラッチ音（短ノイズバースト）+ 閉扉の低い衝撃音。3D定位・距離減衰は強めに
- EV: モーターの低いうなり（のこぎり波を強くフィルタ）+ 到着「チン」（三角波2音）
- 環境: 換気扇のごく低いノイズ（食堂）、冷蔵庫のハム（自室）、遠い車の音は無し（外界の無音が異常さ）

## 実装トリガーの型（events.jsに最低限必要なもの）

zoneEnter(roomId/矩形) / interact(オブジェクトID) / timer(秒) / afterEvent(ID) / counter(既読イベント数) / broadcastSync(何者かの位置に追従する点呼読み上げ)
